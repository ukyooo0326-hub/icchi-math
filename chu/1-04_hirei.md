:::

:::point このスレのテンプレ
比例・反比例の問題はこの順で片づける。

1. 【①全体を見る】ゴールは「式を決める」。値を求めるのはそのあと
2. 【②知識の利用】比例 $y = ax$（$\frac{y}{x}$ が一定）、反比例 $y = \frac{a}{x}$（$xy$ が一定）
3. 【③部分を見る】わかっている **1組の $x$, $y$** を式に代入 → 一次方程式で $a$ を出す
4. 【④工夫する】「2倍したらどうなる？」で比例か反比例かの当たりをつける（できなくていい）

増える・減るでは見分けない。比例定数が負の比例もある。
:::

## 練習問題

:::exercise 基本
$y$ は $x$ に比例し、$x = 3$ のとき $y = 12$ である。$y$ を $x$ の式で表せ。
:::

:::answer
【①全体を見る】ゴールは式を決めること。「比例」なので形は $y = ax$。
【②知識の利用】比例の式 $y = ax$ に、わかっている1組を代入する。
【③部分を見る】$x = 3$、$y = 12$ を代入する。
$$12 = 3a$$
$$a = 4$$
答え：[[$y = 4x$]]

確かめ：$x = 3$ を入れると $y = 12$ になる。
:::

:::exercise 標準
$y$ は $x$ に反比例し、$x = -2$ のとき $y = 9$ である。$y$ を $x$ の式で表し、$x = 3$ のときの $y$ の値を求めよ。
:::

:::answer
【①全体を見る】ゴールは式を決め、$x = 3$ を代入すること。「反比例」なので形は $y = \dfrac{a}{x}$。
【②知識の利用】反比例では $xy = a$（積が一定）。
【③部分を見る】$x = -2$、$y = 9$ を代入する。
$$9 = \frac{a}{-2}$$
両辺に $-2$ をかけて $a = -18$。式は $y = -\dfrac{18}{x}$。
$x = 3$ を代入して $y = -\dfrac{18}{3} = -6$。

答え：[[$y = -\dfrac{18}{x}$、$y = -6$]]

よくあるミス：$a = \dfrac{9}{-2}$ と比例のように割ってしまう。
:::

:::exercise 発展
歯の数が $24$ の歯車 A が毎分 $15$ 回転している。A にかみ合っている歯車 B の歯の数を $x$、毎分の回転数を $y$ とする。$y$ を $x$ の式で表し、B の歯の数が $40$ のときの毎分の回転数を求めよ。
:::

:::answer
【①全体を見る】ゴールは $x$ と $y$ の関係式。比例か反比例かは書いていない。
【②知識の利用】かみ合う2つの歯車は、1分間にかみ合う歯の数が等しい。
（A の歯の数）×（A の回転数）＝（B の歯の数）×（B の回転数）
【③部分を見る】A は1分間に $24 \times 15 = 360$ 個の歯がかみ合う。B も同じなので
$$xy = 360$$
$xy$ が一定なので反比例。式は $y = \dfrac{360}{x}$。
$x = 40$ を代入して $y = \dfrac{360}{40} = 9$。

答え：[[$y = \dfrac{360}{x}$、毎分 $9$ 回転]]

【④工夫する】「B の歯の数を2倍にしたら回転数は $\frac{1}{2}$ 倍」と実験的に考えても、反比例の当たりがつく。確定は③の $xy = 360$ で行う。
:::

:::check ③までやり切れチェック
- ゴールが「まず式を決める」ことだと確認したか
- 比例か反比例かを「$\frac{y}{x}$ 一定」「$xy$ 一定」で判断したか（増える・減るで決めていないか）
- わかっている1組の値を式に代入したか
- 比例定数を一次方程式として解いたか
- 求めた式に元の1組を入れて、成り立つか確かめたか
:::
