## 練習問題

:::exercise 基本
$2(3x - y) - 3(x - 2y)$ を計算せよ。
:::

:::answer
【①全体を見る】カッコが2つ。ゴールは同類項をまとめた形。
【②知識の利用】分配法則でカッコをはずす。$-3$ をかけるときは符号に注意。
$$2(3x - y) - 3(x - 2y) = 6x - 2y - 3x + 6y$$
【③部分を見る】$x$ の項どうし、$y$ の項どうしを集める。
$$= (6x - 3x) + (-2y + 6y)$$
答え：[[$3x + 4y$]]

よくあるミス：$-3 \times (-2y)$ を $-6y$ にしてしまう。負の数どうしの積は正。
:::

:::exercise 標準
偶数と奇数の和は奇数になることを、文字を使って説明せよ。
:::

:::answer
【①全体を見る】ゴールは $2 \times (\text{整数}) + 1$ の形。
【②知識の利用】$m$、$n$ を整数として、偶数を $2m$、奇数を $2n+1$ と表す。
【③部分を見る】偶数と奇数は別々に選ぶ数なので、別の文字を使う。
$$2m + (2n+1) = 2m + 2n + 1 = 2(m+n) + 1$$
$m+n$ は整数だから、$2(m+n)+1$ は [[奇数]] である。

よくあるミス：両方に $n$ を使って $2n + (2n+1)$ とする。これだと「$4$ と $5$」「$6$ と $7$」のような特別な組しか説明できない。
:::

:::exercise 発展
3けたの自然数と、その百の位の数と一の位の数を入れかえた数との差は、99の倍数になることを説明せよ。
:::

:::answer
【①全体を見る】ゴールは $99 \times (\text{整数})$ の形。
【②知識の利用】百の位を $a$、十の位を $b$、一の位を $c$ とすると、もとの数は $100a + 10b + c$。
【③部分を見る】入れかえた数は百の位が $c$、一の位が $a$ なので $100c + 10b + a$。
$$(100a + 10b + c) - (100c + 10b + a) = 99a - 99c$$
$$= 99(a - c)$$
$a - c$ は整数だから、差は [[99の倍数]] である。

【④工夫する】十の位の $10b$ は引き算で消える。「動いていない位は差をとると消える」と予想できると、計算する前にゴールが見える。
:::

:::check ③までやり切れチェック
- ゴールの形（$k \times (\text{整数})$ など）を最初に書いたか
- 例を並べて終わらず、「どんな数でも」を文字でおいたか
- 数どうしに関係があるか見て、文字の個数を決めたか（別々に選ぶ数に同じ文字を使っていないか）
- 計算したあと、「カッコの中は整数だから」と書いたか
:::
