:::point 図形の移動3つ
- 平行移動：一定の方向に一定の距離だけずらす。対応する点を結ぶ線分は [[平行で長さが等しい]]
- 回転移動：点 O を中心に一定の角度だけ回す。[[$OA = OA'$]]、回転角 $\angle AOA'$ はどの点でも等しい
- 対称移動：直線 $\ell$ を折り目に裏返す。対応する点を結ぶ線分は、$\ell$ によって垂直に二等分される
:::

## 練習問題

:::exercise 基本
△ABC を平行移動して △A'B'C' に重ねた。$AA' = 5\,\text{cm}$ のとき、$BB'$ の長さを答えよ。また、線分 $AA'$ と線分 $CC'$ はどんな位置関係にあるか。
:::

:::answer
【①全体を見る】ゴールは $BB'$ の長さと、$AA'$ と $CC'$ の位置関係。
【②知識の利用】平行移動では、対応する点を結ぶ線分は平行で長さが等しい。
【③部分を見る】$AA'$、$BB'$、$CC'$ はどれも「対応する点を結ぶ線分」。
- $BB' = AA' = 5\,\text{cm}$
- $AA'$ と $CC'$ は平行（$AA' \parallel CC'$）

答え：[[$BB' = 5\,\text{cm}$、$AA' \parallel CC'$]]
:::

:::exercise 標準
円 O の周上の点 A を接点とする、円 O の接線を作図する方法を説明せよ。
:::

:::answer
【①全体を見る】ゴールは直線（接線）1本。
【②知識の利用】接線は、接点を通る半径に垂直。
【③部分を見る】求める直線は「点 A を通り、直線 OA に垂直な直線」と言いかえられる。これは基本の作図の垂線。
1. 半径 OA を、A の先まで延ばす
2. A を中心に円をかき、直線 OA との交点を P, Q とする
3. P, Q を中心に同じ半径の円をかき、その交点の1つと A を結ぶ

答え：[[点 A を通る、直線 OA の垂線を引く]]
:::

:::exercise 発展
2直線 $\ell$、$m$ が点 O で交わり、そのなす角は $40°$ である。図形 F を直線 $\ell$ について対称移動し、さらにそれを直線 $m$ について対称移動したところ、図形 F'' になった。F を1回の移動で F'' に重ねるには、どんな移動をすればよいか。
:::

:::answer
【①全体を見る】ゴールは「1回の移動」の種類と、その中身（中心・角度など）。
【②知識の利用】2回裏返すと表に戻るので、平行移動か回転移動。軸が O で交わるので回転移動の候補。
【③部分を見る】F の点 P を1つとり、P → P'（$\ell$ で対称）→ P''（$m$ で対称）と追う。
- 対称の軸上の点 O からの距離は変わらないので、$OP = OP' = OP''$
- 角度：P を $\ell$ 上にとると $P' = P$。そこから $m$ で裏返すと、$\ell$ と $m$ の角 $40°$ の2倍、$\angle POP'' = 80°$

答え：[[点 O を中心に、$\ell$ から $m$ に向かう向きに $80°$ 回転移動する]]

【④工夫する】P を $\ell$ 上にとったのは、1回目の移動で動かない点を選んで計算を楽にする工夫。
:::

:::check ③までやり切れチェック
- ゴールが点か線かを確認したか（点なら線2本の交点）
- 移動の種類（平行・回転・対称）と、その性質を言えたか
- 対応する点の組を1つずつ見て、「2点から等距離」「垂直」に言いかえたか
- 回転の中心を「対応する点の中点」と決めつけていないか
- 接線は、接点を通る半径に垂直な直線として作図したか
:::
