:::point このスレのテンプレ
連立方程式は「文字を1つ消して、一次方程式に送還する」だけ。

1. 【①全体を見る】文字が2つ → [[1つ消して、文字1つの一次方程式にする]] と決める
2. 【②知識の利用】「$y = \cdots$」の形があれば代入法、なければ加減法
3. 【③部分を見る】係数を見て消す文字を選ぶ（符号が逆の文字が狙い目）。何倍かするときは **右辺にも**
4. 【④工夫する】係数が入れかわった形は、足す・引くで $x+y$、$x-y$ を作る

最後に、使っていない方の式で検算する。
:::

## 練習問題

:::exercise 基本
次の連立方程式を解け。
$$\begin{cases} 3x + y = 11 \\ x - y = 1 \end{cases}$$
:::

:::answer
【①全体を見る】文字が2つ。1つ消して一次方程式にする。
【②知識の利用】「$y = $」の形の式はないので加減法。
【③部分を見る】$y$ の係数が $1$ と $-1$ で、符号が逆。そのまま足せば $y$ が消える。
$$4x = 12$$
$$x = 3$$
$x - y = 1$ に代入して $3 - y = 1$、$y = 2$。
検算：$3 \times 3 + 2 = 11$。
答え：[[$x = 3,\ y = 2$]]
:::

:::exercise 標準
次の連立方程式を解け。
$$\begin{cases} 0.2x + 0.3y = 1.3 \\ \dfrac{x}{2} + \dfrac{y}{3} = 2 \end{cases}$$
:::

:::answer
【①全体を見る】文字が2つ。ただし係数が小数・分数でウザい。
【②知識の利用】等式の性質で、両辺に同じ数をかけて係数を整数にする。上の式は $10$ 倍、下の式は分母の最小公倍数 $6$ 倍（右辺にもかける）。
$$2x + 3y = 13$$
$$3x + 2y = 12$$
【③部分を見る】$x$ の係数を $6$ にそろえる。上を3倍、下を2倍して
$$6x + 9y = 39$$
$$6x + 4y = 24$$
上から下を引いて $5y = 15$、$y = 3$。$2x + 9 = 13$ より $x = 2$。
答え：[[$x = 2,\ y = 3$]]

【④工夫する】整数にした2式は係数が入れかわった形。足すと $5x + 5y = 25$ で $x + y = 5$ がすぐ出る。
:::

:::exercise 発展
1個120円のりんごと1個80円のみかんを、合わせて10個買ったら、代金は1040円だった。りんごとみかんをそれぞれ何個買ったか求めよ。
:::

:::answer
【①全体を見る】求めるものが2つ。りんごを $x$ 個、みかんを $y$ 個として、式を2本作る。
【②知識の利用】「個数の関係」と「代金の関係」で式を立てる。
$$x + y = 10$$
$$120x + 80y = 1040$$
【③部分を見る】下の式は全部 $40$ で割れる。両辺を $40$ で割って $3x + 2y = 26$。
上の式から $y = 10 - x$。これを代入して
$$3x + 2(10 - x) = 26$$
$$x + 20 = 26$$
$x = 6$、$y = 4$。
検算：$120 \times 6 + 80 \times 4 = 720 + 320 = 1040$。
答え：[[りんご6個、みかん4個]]
:::

:::check ③までやり切れチェック
- 文字が2つあるとき、「1つ消す」と最初に決めたか
- 「$y = \cdots$」の形の式があるか見て、代入法か加減法かを選んだか
- 係数を見て、消す文字を選んだか（符号が逆の文字が狙い目）
- 式を何倍かしたとき、右辺にもかけたか
- 代入するときにカッコをつけ、最後に使っていない方の式で検算したか
:::
