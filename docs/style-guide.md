# 原稿スタイルガイド（これが唯一の正）

## 0. 1スレ＝1単元
各ファイルは「イッチが立てたスレ」1本。イッチが問題に詰まる → 住人と4ステップで解体 → イッチが自力で最後まで解く → 練習問題、の流れ。
長さの目安：**本編のレス 35〜60 個**、ファイル全体 300〜500 行。

## 1. 記法（`tools/build.py` が解釈する）

### 1-1. フロントマター（必須）
```
---
title: 【悲報】イッチ、因数分解でどこから手をつけるかわからない
unit: 中3・展開と因数分解
goal: 因数分解を「共通因数 → 公式 → 置換」の順で迷わず試せる
prereq: 分配法則、乗法公式（展開）
core: どんな式も「知っている公式の形」に強制送還してから解く
---
```

### 1-2. レス
行頭 `@番号 名前` でレスが始まり、次の `@` 行・`:::` ブロック・`##` 見出しまで続く。
```
@1 イッチ
数学の宿題でたんやが
$x^2 - 5x + 6$ を因数分解しろってなに？

@2 名無し
>>1
うぽつ
```
- 名前は **`イッチ` / `古参ニキ` / `名無し`** の3種のみ（同じ名無しが複数いてよい）。
- レス番号は 1 から連番。**飛ばさない・重複させない**。
- `>>12` と書くとアンカーになる（存在するレス番号だけ指すこと）。
- 日付・ID はビルド時に自動生成。書かない。

### 1-3. インライン
| 記法 | 意味 |
|---|---|
| `$...$` | インライン数式（KaTeX） |
| `$$...$$`（単独行） | ディスプレイ数式 |
| `[[語句]]` | **赤字（赤シートで消える）**。定義・公式の核・答え |
| `**語句**` | 太字（黒・消えない強調） |
| `【①全体を見る】` `【②知識の利用】` `【③部分を見る】` `【④工夫する】` | 4ステップのバッジ。**この表記を一字一句そのまま使う** |
| `>>番号` | アンカー |

- `[[ ]]` の中に `$...$` を入れてよい：`[[$a^2-b^2=(a+b)(a-b)$]]`
- 赤字は 1 レスに多くても 2 か所。乱発すると赤シートの意味がなくなる。

### 1-4. ブロック
```
:::point タイトル
- 箇条書きや段落
:::
```
| 種類 | 用途 |
|---|---|
| `:::point` | 古参ニキのまとめ・テンプレ（本編中に 1〜3 個、最後に必ず 1 個「このスレのテンプレ」） |
| `:::warn` | よくある勘違い・落とし穴 |
| `:::exercise` | 練習問題 1 問（タイトルに `基本` / `標準` / `発展`） |
| `:::answer` | 直前の練習問題の解答（折りたたみ表示）。**必ず 4 ステップのバッジで手順を書く** |
| `:::check` | 最後の「③までやり切れチェック」 |

ブロック内で使えるもの：段落、`- ` 箇条書き、`1. ` 番号付き、数式、インライン記法、`|` 表。
`##` 見出しはブロックの外でのみ使う（例：`## 練習問題`）。

## 2. 章の構成（この順で）
1. フロントマター
2. 本編スレ（レス 35〜60）
   - **導入（〜レス8）**：イッチが問題を貼る。「めんどくさい」「帰っていい？」。名無しが煽る or 便乗。
   - **展開**：古参ニキ登場。いきなり答えを言わず「**どこがウザい？**」と聞く。4ステップを順番に回す。
   - **山場**：イッチがやらかす（典型的な勘違い）→ 名無しがツッコむ → 古参ニキが「なぜそう間違えるか」を本質から説明。
   - **自走**：類題をイッチが **自力で** 4ステップを宣言しながら解く。ここで「解けた！」「え、ワイ天才では？」の原体験。
   - **締め**：古参ニキの `:::point このスレのテンプレ`。イッチの捨て台詞（「めんどくさいけど…まあ、わかったわ」系）。
3. `## 練習問題` … `:::exercise` 基本・標準・発展 の 3 問、それぞれ直後に `:::answer`
4. `:::check ③までやり切れチェック` … その単元で「③部分を見る」までに必ずやる行動を 3〜5 個

## 3. 数学の品質基準（math-educator）
- **既知への還元**を毎回明言する：「これは〇〇（既に知ってる形）に帰着できる」。
- 4ステップの順序を守る：①で全体（ゴール・構造・次数・何を求める問題か）→ ②で使える知識を検索 → ②で即決しないときに ③ で部分化・置換 → それでもダメなら ④。
- **③までは機械的にできる手順**として書く。④はひらめき扱いでよいが「なぜその工夫を思いつけるか」の理由を一言添える。
- 式変形は 1 行で 1 操作。飛ばすとき（暗算する箇所）は名無しに「今の行間なに？」とツッコませて埋める。
- 計算・答えは必ず検算する（Python 等で確認してよい）。間違いは致命傷。
- 用語は教科書準拠（中学：「変化の割合」「比例定数」など、高校：「判別式」「必要条件」など）。
- 学年をまたぐ知識を前提にしない（中1の章で平方根を使わない、など）。後の単元への予告はOK。

## 4. スレの品質基準（meme-editor）
### キャラ
| | 一人称 | 口調 | 役割 |
|---|---|---|---|
| **イッチ** | ワイ | 関西寄りなんJ語。「〜やん」「〜ンゴ」「帰っていい？」「めんどくさ」 | 数学嫌い。素朴な疑問・典型的な勘違いを代弁。最後は自力で解く |
| **古参ニキ** | ワイ / こっち | 落ち着いたネット口調。「せやな」「ええか」「〜定期」。上から目線にしない | 本質を短く突く。答えより「どこを見るか」を教える |
| **名無し** | （なし） | 短文。煽り・便乗・ツッコミ・草 | テンポを作る。行間を質問する。イッチの代弁もする |

### 使ってよいスラング（例）
うぽつ / ksk / kwsk / 草 / 大草原 / それな / せやな / ファッ！？ / はえ〜すっごい / 有能 / 神 / ニキ / ネキ / 〜定期 / 〜で草 / ガチ / ワイ / ンゴ / （白目） / 優勝 / 天才か？ / 〜民 / 悲報・朗報 / 正論パンチ / 知ってた / 名スレ / 保守

### 禁止
- 差別語・容姿いじり・性的な表現・特定個人や実在企業への中傷・「死ね」「ガイジ」等の暴言
- 勉強できない人をバカにするオチ（煽るのはOK、人格否定はNG）
- 1レスが 6 行を超える長文（古参ニキの解説でも 6 行目安で切って連投する）
- 実在の塾名・参考書名・ブランド名

### テンポ
- 古参ニキの解説レスの間に、名無しの短いリアクションを 1〜2 個はさむ。
- 1 つのレスで新しい概念は 1 個まで。
- 4ステップのバッジは **古参ニキかイッチのレスで宣言する**（名無しは使わない）。

## 5. レイアウト基準（ui-designer）
- `[[赤字]]` は「定義・公式・答え」の 3 種だけ。
- 見出し階層：`##` は「練習問題」「（任意で）中間まとめ」の 2〜3 個まで。
- 数式は長くなったら `$$` で独立行に。インラインは 1 行 1 個を目安。
- 図が必要な問題は文章で十分に状況が再現できるようにする（図は後工程で追加）。図を想定する箇所には `（図：〇〇）` と書いておく。
