:::

## 練習問題

:::exercise 基本
$\displaystyle\sum_{k=1}^{n} (3k^2 - k)$ を計算せよ。
:::

:::answer
【①全体を見る】ゴールは $n$ の式。和の中身は $k^2$ の項と $k$ の項。
【②知識の利用】Σ は分けてよい。
$$\sum_{k=1}^{n} (3k^2 - k) = 3\sum_{k=1}^{n} k^2 - \sum_{k=1}^{n} k = 3 \cdot \frac{1}{6}n(n+1)(2n+1) - \frac{1}{2}n(n+1)$$
【③部分を見る】共通因数 $\frac{1}{2}n(n+1)$ でくくる（展開しない方が速い）。
$$= \frac{1}{2}n(n+1)\{(2n+1) - 1\} = \frac{1}{2}n(n+1) \cdot 2n$$
答え：[[$n^2(n+1)$]]

検算：$n = 1$ のとき $3 - 1 = 2$、式は $1 \times 2 = 2$。$n = 2$ のとき $2 + 10 = 12$、式は $4 \times 3 = 12$。
:::

:::exercise 標準
$a_1 = 2$、$a_{n+1} = a_n + 4n - 1$ で定められる数列 $\{a_n\}$ の一般項を求めよ。
:::

:::answer
【①全体を見る】$a_{n+1} - a_n = 4n - 1$。差が $n$ によって変わる。
【②知識の利用】階差型。階差数列は $b_n = 4n - 1$。$n \geqq 2$ のとき
$$a_n = 2 + \sum_{k=1}^{n-1} (4k - 1)$$
【③部分を見る】Σ の上端は $n - 1$。公式の $n$ を $n - 1$ に置き換える。
$$\sum_{k=1}^{n-1} (4k - 1) = 4 \cdot \frac{1}{2}(n-1)n - (n - 1) = 2n^2 - 3n + 1$$
よって $a_n = 2n^2 - 3n + 3$。
$n = 1$ のとき $2 - 3 + 3 = 2 = a_1$ なので、$n = 1$ でも成り立つ。
答え：[[$a_n = 2n^2 - 3n + 3$]]
:::

:::exercise 発展
数列 $\{a_n\}$ の初項から第 $n$ 項までの和 $S_n$ が、$S_n = 2a_n - n$ $(n = 1, 2, 3, \ldots)$ を満たす。一般項 $a_n$ を求めよ。
:::

:::answer
【①全体を見る】式に $S_n$ と $a_n$ が混ざっている。ゴールは $a_n$ だけの式なので、まず $S_n$ を消す。
【②知識の利用】$a_1 = S_1$、$a_{n+1} = S_{n+1} - S_n$。
$n = 1$ のとき $a_1 = 2a_1 - 1$ より $a_1 = 1$。
【③部分を見る】$S_{n+1} = 2a_{n+1} - (n+1)$ と $S_n = 2a_n - n$ の差をとる。
$$a_{n+1} = 2a_{n+1} - 2a_n - 1 \quad\Rightarrow\quad a_{n+1} = 2a_n + 1$$
【④工夫する】特性方程式 $\alpha = 2\alpha + 1$ より $\alpha = -1$。$a_{n+1} + 1 = 2(a_n + 1)$。
$\{a_n + 1\}$ は初項 $a_1 + 1 = 2$、公比 $2$ の等比数列なので $a_n + 1 = 2 \cdot 2^{n-1} = 2^n$。
答え：[[$a_n = 2^n - 1$]]

検算：$S_n = \displaystyle\sum_{k=1}^{n}(2^k - 1) = 2^{n+1} - 2 - n$、$2a_n - n = 2^{n+1} - 2 - n$ で一致。
:::
