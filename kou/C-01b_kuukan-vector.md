## 練習問題

:::exercise 基本
$\vec{a} = (1,\ 1,\ 0)$、$\vec{b} = (1,\ 0,\ 1)$ のなす角 $\theta$（$0^\circ \leqq \theta \leqq 180^\circ$）を求めよ。
:::

:::answer
【①全体を見る】ゴールはなす角。$\cos\theta$ を出す。
【②知識の利用】$\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$。空間でも成分は3つ足すだけ。
【③部分を見る】内積と大きさを別々に。
$\vec{a} \cdot \vec{b} = 1 \times 1 + 1 \times 0 + 0 \times 1 = 1$、$|\vec{a}| = |\vec{b}| = \sqrt{2}$
$$\cos\theta = \frac{1}{\sqrt{2} \cdot \sqrt{2}} = \frac{1}{2}$$
答え：[[$\theta = 60^\circ$]]
:::

:::exercise 標準
4点 $\mathrm{A}(1,\ 1,\ 1)$、$\mathrm{B}(2,\ 3,\ 1)$、$\mathrm{C}(3,\ 1,\ 2)$、$\mathrm{D}(x,\ 5,\ 3)$ が同一平面上にあるとき、$x$ の値を求めよ。
:::

:::answer
【①全体を見る】同一平面上の条件。A を始点にして考える。
【②知識の利用】D が平面 ABC 上 $\iff$ $\overrightarrow{AD} = s\overrightarrow{AB} + t\overrightarrow{AC}$。
【③部分を見る】成分を出す。$\overrightarrow{AB} = (1,\ 2,\ 0)$、$\overrightarrow{AC} = (2,\ 0,\ 1)$、$\overrightarrow{AD} = (x - 1,\ 4,\ 2)$。
成分を比べて
$$x - 1 = s + 2t, \quad 4 = 2s, \quad 2 = t$$
2本目・3本目から $s = 2$、$t = 2$。1本目に代入して $x - 1 = 6$。
答え：[[$x = 7$]]

$\overrightarrow{AB}$ と $\overrightarrow{AC}$ は成分が比例していないので平行でない（平面 ABC が1つに決まる）。
:::

:::exercise 発展
球面 $x^2 + y^2 + z^2 - 2x + 4y - 6z - 2 = 0$ の中心と半径を求めよ。また、この球面と $xy$ 平面が交わってできる円の中心と半径を求めよ。
:::

:::answer
【①全体を見る】展開された形なので、中心・半径が見えない。標準形 $(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$ に直す。
【②知識の利用】数IIの円と同じく、$x, y, z$ それぞれ平方完成。
$$(x - 1)^2 + (y + 2)^2 + (z - 3)^2 = 2 + 1 + 4 + 9 = 16$$
答え：中心 [[$(1,\ -2,\ 3)$、半径 $4$]]
【③部分を見る】$xy$ 平面は $z = 0$。代入すると
$$(x - 1)^2 + (y + 2)^2 + 9 = 16 \quad\Rightarrow\quad (x - 1)^2 + (y + 2)^2 = 7$$
答え：$xy$ 平面上で中心 [[$(1,\ -2,\ 0)$、半径 $\sqrt{7}$]] の円

【④工夫する】中心から $xy$ 平面までの距離は $|z| = 3$。三平方で $\sqrt{4^2 - 3^2} = \sqrt{7}$ と検算できる。
:::
