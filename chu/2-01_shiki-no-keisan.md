## 練習問題

:::exercise 基本
次の計算をせよ。また (3) の等式を $y$ について解け。
(1) $2(3x - y) - 3(x - 2y)$　(2) $12x^2y \div \dfrac{4}{3}xy$　(3) $3x + 2y = 6$
:::

:::answer
(1) 【①全体を見る】ゴールは同類項をまとめた多項式。【②知識の利用】分配法則でカッコをはずす。
$$2(3x - y) - 3(x - 2y) = 6x - 2y - 3x + 6y$$
【③部分を見る】$x$ の項どうし、$y$ の項どうしを集めて $3x + 4y$。$-3 \times (-2y) = +6y$ に注意。

(2) 【①全体を見る】ゴールは1つの単項式。【②知識の利用】わる式の逆数をかける。$\dfrac{4}{3}xy = \dfrac{4xy}{3}$ の逆数は $\dfrac{3}{4xy}$。
$$12x^2y \times \frac{3}{4xy} = \frac{12 \times 3 \times x \times x \times y}{4 \times x \times y}$$
【③部分を見る】数どうし・文字どうしで約分して $9x$。よくあるミス：$\times \dfrac{3}{4}xy$ として $9x^3y^2$ にする。

(3) 【①全体を見る】ゴールは $y = \cdots$ の形。【②知識の利用】$y$ を $x$ とみて一次方程式と同じ手順。
【③部分を見る】$3x$ を移項して $2y = 6 - 3x$、両辺を $2$ でわって $y = \dfrac{6 - 3x}{2}$（$y = 3 - \dfrac{3}{2}x$ でもよい）。

答え：[[(1) $3x + 4y$　(2) $9x$　(3) $y = \dfrac{6 - 3x}{2}$]]
:::

:::exercise 標準
偶数と奇数の和は奇数になることを、文字を使って説明せよ。
:::

:::answer
【①全体を見る】ゴールは $2 \times (\text{整数}) + 1$ の形。
【②知識の利用】$m$、$n$ を整数として、偶数を $2m$、奇数を $2n+1$ と表す。
【③部分を見る】偶数と奇数は別々に選ぶ数なので、別の文字を使う。
$$2m + (2n+1) = 2m + 2n + 1 = 2(m+n) + 1$$
$m+n$ は整数だから、$2(m+n)+1$ は [[奇数]] である。

よくあるミス：両方に $n$ を使って $2n + (2n+1)$ とする。これだと「$4$ と $5$」「$6$ と $7$」のような特別な組しか説明できない。
:::

:::exercise 発展
3けたの自然数と、その百の位の数と一の位の数を入れかえた数との差は、99の倍数になることを説明せよ。
:::

:::answer
【①全体を見る】ゴールは $99 \times (\text{整数})$ の形。
【②知識の利用】百の位を $a$、十の位を $b$、一の位を $c$ とすると、もとの数は $100a + 10b + c$。
【③部分を見る】入れかえた数は百の位が $c$、一の位が $a$ なので $100c + 10b + a$。
$$(100a + 10b + c) - (100c + 10b + a) = 99a - 99c$$
$$= 99(a - c)$$
$a - c$ は整数だから、差は [[99の倍数]] である。

【④工夫する】十の位の $10b$ は引き算で消える。「動いていない位は差をとると消える」と予想できると、計算する前にゴールが見える。
:::

:::check ③までやり切れチェック
- ゴールの形（1つの単項式、$h = \cdots$、$k \times (\text{整数})$ など）を最初に書いたか
- わり算を分数の形（逆数のかけ算）にしてから、数どうし・文字どうしで約分したか
- 例を並べて終わらず、「どんな数でも」を文字でおいたか
- 数どうしに関係があるか見て、文字の個数を決めたか（別々に選ぶ数に同じ文字を使っていないか）
- 計算したあと、「カッコの中は整数だから」と書いたか
:::
