## 練習問題

:::exercise 基本
(1) 関数 $y = -2x^2 + 4x + 1$ $(-1 \le x \le 2)$ の最大値と最小値を求めよ。
(2) グラフが3点 $(-1,\ 0)$, $(1,\ 4)$, $(2,\ 3)$ を通る2次関数を求めよ。
:::

:::answer
【①全体を見る】$x^2$ の係数が負なので上に凸。定義域は $-1 \le x \le 2$。
【②知識の利用】平方完成。$-2$ でくくって中括弧を書く。
$$-2x^2 + 4x + 1 = -2(x^2 - 2x) + 1$$
$$= -2\{(x-1)^2 - 1\} + 1 = -2(x-1)^2 + 3$$
頂点 $(1,\ 3)$、軸 $x = 1$。
【③部分を見る】軸 $x = 1$ は定義域の中。上に凸なので頂点が最大。最小は軸から遠い端。
- 軸からの距離：$x = -1$ は $2$、$x = 2$ は $1$。遠いのは $x = -1$
- $x = -1$ のとき $y = -2 - 4 + 1 = -5$

答え：[[最大値 $3$（$x = 1$）、最小値 $-5$（$x = -1$）]]

上に凸のときは「下に凸」の最大と最小が入れ替わる。

(2)
【①全体を見る】条件は「3点を通る」。頂点はわからない。
【②知識の利用】3点なら $y = ax^2 + bx + c$ とおいて代入する。
$$a - b + c = 0,\quad a + b + c = 4,\quad 4a + 2b + c = 3$$
【③部分を見る】1本目と2本目を引くと $2b = 4$ で $b = 2$。残りは $a + c = 2$、$4a + c = -1$ の連立方程式。引いて $3a = -3$ より $a = -1$、$c = 3$。
答え：[[$y = -x^2 + 2x + 3$]]

検算：3点を代入すると $0$, $4$, $3$ で一致。平方完成すると $y = -(x-1)^2 + 4$ で、点 $(1,\ 4)$ は頂点だった。
:::

:::exercise 標準
すべての実数 $x$ について $x^2 + 2ax + a + 6 > 0$ が成り立つような、定数 $a$ の値の範囲を求めよ。
:::

:::answer
【①全体を見る】「すべての実数 $x$ で $y > 0$」＝「下に凸のグラフ $y = x^2 + 2ax + a + 6$ が、常に $x$ 軸より上」。
【②知識の利用】$x$ 軸と共有点をもたなければよい。判別式 $D < 0$。
【③部分を見る】$D$ を計算する。
$$D = (2a)^2 - 4 \cdot 1 \cdot (a + 6) = 4(a^2 - a - 6)$$
$D < 0$ より $a^2 - a - 6 < 0$。因数分解して
$$(a+2)(a-3) < 0$$
グラフが横軸より下の部分を読んで、答え：[[$-2 < a < 3$]]

「すべての $x$ で正」をグラフの位置に翻訳するのが決め手。
:::

:::exercise 発展
$a$ は定数とする。関数 $f(x) = x^2 - 2ax + 2a + 3$ $(0 \le x \le 2)$ の最小値が $0$ となるような $a$ の値を求めよ。
:::

:::answer
【①全体を見る】ゴールは「最小値 $= 0$」となる $a$。まず最小値を $a$ で表す。
【②知識の利用】平方完成。
$$f(x) = (x-a)^2 - a^2 + 2a + 3$$
軸 $x = a$、下に凸。
【③部分を見る】軸の位置で3通りに場合分けし、それぞれ「最小値 $= 0$」を解く。
- $a < 0$ のとき：最小値 $f(0) = 2a + 3$。$2a + 3 = 0$ より $a = -\dfrac{3}{2}$。これは $a < 0$ をみたす。
- $0 \le a \le 2$ のとき：最小値 $f(a) = -a^2 + 2a + 3$。$-a^2 + 2a + 3 = 0$ より $(a-3)(a+1) = 0$、$a = 3, -1$。どちらも $0 \le a \le 2$ をみたさないので不適。
- $a > 2$ のとき：最小値 $f(2) = 4 - 4a + 2a + 3 = 7 - 2a$。$7 - 2a = 0$ より $a = \dfrac{7}{2}$。これは $a > 2$ をみたす。

答え：[[$a = -\dfrac{3}{2},\ \dfrac{7}{2}$]]

よくあるミス：場合分けの中で出た $a$ が、その場合の範囲に入っているかを確認し忘れる（$a = 3$ や $a = -1$ を答えに入れてしまう）。
:::

:::check ③までやり切れチェック
- $x^2$ の係数の符号を見て、上に凸か下に凸かを確認したか
- 平方完成で、くくった係数を後ろの定数にもかけたか（$x = p$ を代入して検算したか）
- 2次関数の決定では、頂点がわかれば頂点の形、3点なら一般形でおいたか
- 定義域を数直線に描き、軸の位置を書き込んだか
- 軸の位置が文字で決まらないとき、軸を左から右へ動かして場合分けしたか
- 場合分けの境目（等号）に抜けや重なりがないか、求めた値がその場合の範囲に入っているか
:::
