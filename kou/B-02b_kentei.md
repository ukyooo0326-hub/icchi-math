## 練習問題

:::exercise 基本
確率変数 $X$ のとる値の範囲が $0 \leqq X \leqq 2$ で、確率密度関数が $f(x) = ax$（$a$ は定数）であるとする。
(1) $a$ の値を求めよ。
(2) $P(1 \leqq X \leqq 2)$ を求めよ。
:::

:::answer
【①全体を見る】確率は面積。全体の面積は1。
【②知識の利用】$\displaystyle\int_0^2 f(x)\,dx = 1$、$P(a \leqq X \leqq b) = \displaystyle\int_a^b f(x)\,dx$。
【③部分を見る】(1) 全体の面積を計算する。
$$\int_0^2 ax\,dx = \left[\frac{a}{2}x^2\right]_0^2 = 2a = 1$$
(1) 答え：[[$a = \dfrac{1}{2}$]]
(2) 区間 $1 \leqq x \leqq 2$ の面積。
$$\int_1^2 \frac{1}{2}x\,dx = \left[\frac{x^2}{4}\right]_1^2 = 1 - \frac{1}{4} = \frac{3}{4}$$
(2) 答え：[[$\dfrac{3}{4}$]]
:::

:::exercise 標準
ある地域で無作為に選んだ有権者400人のうち、160人がある政策を支持していた。この地域の支持率 $p$ に対する信頼度95%の信頼区間を求めよ（小数第3位まで）。
:::

:::answer
【①全体を見る】ゴールは母比率 $p$ の範囲。
【②知識の利用】信頼区間は $R \pm 1.96\sqrt{\dfrac{R(1 - R)}{n}}$。
【③部分を見る】まず標本比率とばらつきを出す。$R = \dfrac{160}{400} = 0.4$。
$$\sqrt{\frac{0.4 \times 0.6}{400}} = \sqrt{0.0006} \fallingdotseq 0.0245$$
$1.96 \times 0.0245 \fallingdotseq 0.048$ なので
$$0.4 - 0.048 \leqq p \leqq 0.4 + 0.048$$
答え：[[$0.352 \leqq p \leqq 0.448$]]
:::

:::exercise 発展
これまでの薬で治る割合は $0.5$ である。新しい薬を100人に使ったところ、59人が治った。新しい薬はこれまでの薬より治る割合が高いと判断してよいか。有意水準5%で検定せよ。ただし $P(0 \leqq Z \leqq 1.64) = 0.4495$ とする。
:::

:::answer
【①全体を見る】言いたいのは「高い」。治る割合を $p$ として $H_0$：$p = 0.5$、$H_1$：$p > 0.5$。「高い」なので **片側検定**。
【②知識の利用】$H_0$ のもとで治る人数 $X$ は $B(100, 0.5)$。$E(X) = 50$、$V(X) = 100 \times 0.5 \times 0.5 = 25$、$\sigma = 5$。近似的に $N(50, 5^2)$。
【③部分を見る】標準化：$Z = \dfrac{59 - 50}{5} = 1.8$。片側の棄却域は $Z \geqq 1.64$。$1.8 \geqq 1.64$ なので棄却域に入る。
答え：[[$H_0$ は棄却され、治る割合が高いと判断してよい]]

よくあるミス：両側の棄却域 $|Z| \geqq 1.96$ を使い、「判断できない」とする。問題文の「高い」は片側。
:::

- 言いたいことを対立仮説 $H_1$、否定したいことを帰無仮説 $H_0$ として書いたか
- 問題文から両側か片側かを判断したか
- $H_0$ のもとでの平均・標準偏差を出し、標準化したか
- 棄却域と比べ、棄却できないときに「判断できない」と書いたか

:::
