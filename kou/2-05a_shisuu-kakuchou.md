## 練習問題

:::exercise 基本
次の計算をせよ。ただし (3) では $a > 0$ とする。
(1) $16^{\frac{3}{4}}$　(2) $\sqrt[3]{24} \times \sqrt[3]{9}$　(3) $\sqrt{a} \times \sqrt[3]{a^2} \div \sqrt[6]{a}$
:::

:::answer
【①全体を見る】すべて「同じ底の何乗か」で書いて、指数法則で計算する。
【②知識の利用】$a^{\frac{m}{n}} = \sqrt[n]{a^m}$、$a^r a^s = a^{r+s}$。
【③部分を見る】
(1) $16 = 2^4$ より $16^{\frac{3}{4}} = 2^{4 \times \frac{3}{4}} = 2^3 = 8$
(2) $\sqrt[3]{24} \times \sqrt[3]{9} = \sqrt[3]{216} = \sqrt[3]{6^3} = 6$
(3) $a^{\frac{1}{2}} \times a^{\frac{2}{3}} \div a^{\frac{1}{6}} = a^{\frac{1}{2} + \frac{2}{3} - \frac{1}{6}} = a^{\frac{3 + 4 - 1}{6}} = a^1$
答え：[[(1) $8$　(2) $6$　(3) $a$]]
:::

:::exercise 標準
3つの数 $\sqrt[3]{\dfrac{1}{4}},\ \left(\dfrac{1}{2}\right)^{\frac{1}{2}},\ \dfrac{1}{\sqrt[5]{8}}$ の大小を比べよ。
:::

:::answer
【①全体を見る】全部 $\dfrac{1}{2}$ の何乗かで書けそう。
【②知識の利用】$\sqrt[3]{\dfrac{1}{4}} = \left(\left(\dfrac{1}{2}\right)^2\right)^{\frac{1}{3}} = \left(\dfrac{1}{2}\right)^{\frac{2}{3}}$、$\dfrac{1}{\sqrt[5]{8}} = \left(\dfrac{1}{2^3}\right)^{\frac{1}{5}} = \left(\dfrac{1}{2}\right)^{\frac{3}{5}}$
【③部分を見る】肩は $\dfrac{1}{2} < \dfrac{3}{5} < \dfrac{2}{3}$（通分して $\dfrac{15}{30} < \dfrac{18}{30} < \dfrac{20}{30}$）。
底 $\dfrac{1}{2}$ は $1$ より小さいので、肩が大きいほど小さい。
答え：[[$\sqrt[3]{\dfrac{1}{4}} < \dfrac{1}{\sqrt[5]{8}} < \left(\dfrac{1}{2}\right)^{\frac{1}{2}}$]]

本編 >>38 と肩の並びは同じなのに、向きがまるごと逆になる。
:::

:::exercise 発展
不等式 $\left(\dfrac{1}{3}\right)^{2x - 1} \le 27 < \left(\dfrac{1}{3}\right)^{x - 4}$ を解け。
:::

:::answer
【①全体を見る】2つの不等式の連立。それぞれ解いて共通部分をとる。
【②知識の利用】底を $3$ にそろえる。$\left(\dfrac{1}{3}\right)^{2x-1} = 3^{-(2x-1)} = 3^{1-2x}$、$\left(\dfrac{1}{3}\right)^{x-4} = 3^{4-x}$、$27 = 3^3$。
$$3^{1 - 2x} \le 3^3 < 3^{4 - x}$$
【③部分を見る】底 $3 > 1$ なので向きはそのまま。肩だけ比べる。
- $1 - 2x \le 3$ より $x \ge -1$
- $3 < 4 - x$ より $x < 1$

答え：[[$-1 \le x < 1$]]

【④工夫する】底 $\dfrac{1}{3}$ のまま解いてもよいが、$1$ より大きい底にそろえると向きを逆にする操作が要らなくなり、ミスが減る。
:::

:::check ③までやり切れチェック
- ルート・分数・マイナスの指数を、同じ底の「何乗か」に書き直したか
- $a^0 = 1$、$a^{-n} = \dfrac{1}{a^n}$ を符号を変えずに使えたか
- 肩を比べる前に、底が $1$ より大きいか小さいかを確認したか
- 底が $1$ より小さいとき、不等号の向きを逆にしたか
- 答えの範囲の内側と外側の値を代入して検算したか
:::
