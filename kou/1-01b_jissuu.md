## 練習問題

:::exercise 基本
(1) 循環小数 $0.1\dot{2}\dot{3}$ を分数で表せ。
(2) $\dfrac{\sqrt{3}+1}{\sqrt{3}-1}$ の分母を有理化せよ。
:::

:::answer
(1)
【①全体を見る】$x = 0.1232323\cdots$ とおく。くり返すのは「23」の2桁で、小数第2位から始まる。
【③部分を見る】尻尾をそろえるため、$1000$ 倍と $10$ 倍を作る。
$$1000x = 123.2323\cdots$$
$$10x = 1.2323\cdots$$
引くと尻尾が消えて $990x = 122$。
答え：[[$\dfrac{61}{495}$]]

(2)
【②知識の利用】分母 $\sqrt{3}-1$ には、和と差の積になる $\sqrt{3}+1$ を分母・分子にかける。
$$\frac{(\sqrt{3}+1)^2}{(\sqrt{3}-1)(\sqrt{3}+1)} = \frac{4+2\sqrt{3}}{3-1}$$
【③部分を見る】分子は $(\sqrt{3})^2 + 2\sqrt{3} + 1 = 4 + 2\sqrt{3}$。$2$ で約分する。
答え：[[$2+\sqrt{3}$]]

よくあるミス：(1) で $100$ 倍して引くと、$99x = 12.2$ のように小数が残る。くり返しの **始まりの位置** をそろえる。
:::

:::exercise 標準
連立不等式 $5x - 3 > 2x + 6$、$3(x-1) \le x + 7$ を解け。また、これを満たす整数 $x$ をすべて求めよ。
:::

:::answer
【①全体を見る】不等式2本の連立。1本ずつ解いてから共通部分をとる。
【②知識の利用】それぞれ一次不等式として解く。
- $5x - 3 > 2x + 6$ より $3x > 9$、$x > 3$
- $3(x-1) \le x + 7$ より $3x - 3 \le x + 7$、$2x \le 10$、$x \le 5$

【③部分を見る】数直線に描く。$3$ は白丸、$5$ は黒丸。重なりは $3 < x \le 5$。
（図：数直線上の $x > 3$ と $x \le 5$ の共通部分）
答え：[[$3 < x \le 5$、整数は $x = 4,\ 5$]]

よくあるミス：$x = 3$ を入れる。$x > 3$ は白丸なので $3$ は含まない。
:::

:::exercise 発展
(1) 不等式 $|x+1| + |x-2| < 5$ を解け。
(2) $\sqrt{7 - 2\sqrt{10}}$ を簡単にせよ。
:::

:::answer
(1)
【①全体を見る】絶対値が2つ。それぞれ中身の符号で外す。
【②知識の利用】絶対値は定義で外す。
【③部分を見る】境目は $x = -1$ と $x = 2$。数直線を3つの区間に分ける。
- $x < -1$ のとき：$-(x+1) - (x-2) < 5$ より $-2x + 1 < 5$、$x > -2$。範囲と重ねて $-2 < x < -1$
- $-1 \le x < 2$ のとき：$(x+1) - (x-2) = 3 < 5$ で常に成り立つ。$-1 \le x < 2$
- $x \ge 2$ のとき：$(x+1) + (x-2) < 5$ より $2x < 6$、$x < 3$。範囲と重ねて $2 \le x < 3$

3つを合わせて、答え：[[$-2 < x < 3$]]

(2)
【④工夫する】$(\sqrt{a}-\sqrt{b})^2 = a + b - 2\sqrt{ab}$ の逆読み。足して $7$、かけて $10$ の2数は $5$ と $2$。
$$\sqrt{7 - 2\sqrt{10}} = \sqrt{(\sqrt{5}-\sqrt{2})^2} = |\sqrt{5}-\sqrt{2}|$$
$\sqrt{5} > \sqrt{2}$ なので、答え：[[$\sqrt{5}-\sqrt{2}$]]

$\sqrt{2}-\sqrt{5}$ と書くと負の数になってしまう。$\sqrt{a^2} = |a|$ を思い出す。
:::

- $\sqrt{a^2}$ を外す前に、$a$ の符号を調べたか
- 絶対値の中身の符号が変わる境目を求め、場合ごとに範囲と重ねたか
- 連立不等式を数直線に描き、白丸・黒丸を区別して共通部分を読んだか
:::
