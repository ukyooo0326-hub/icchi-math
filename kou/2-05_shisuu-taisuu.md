## 練習問題

:::exercise 基本
$\log_2 12 - \log_2 3 + \log_4 8$ を計算せよ。
:::

:::answer
【①全体を見る】底が $2$ と $4$ でバラバラ。底をそろえる。
【②知識の利用】前の2つは引き算 → 割り算にまとめる。
$$\log_2 12 - \log_2 3 = \log_2 \frac{12}{3} = \log_2 4 = 2$$
【③部分を見る】$\log_4 8$ は底の変換公式で底を $2$ に。
$$\log_4 8 = \frac{\log_2 8}{\log_2 4} = \frac{3}{2}$$
よって $2 + \dfrac{3}{2} = \dfrac{7}{2}$。
答え：[[$\dfrac{7}{2}$]]
:::

:::exercise 標準
不等式 $\log_2(x - 1) + \log_2(x - 3) \le 3$ を解け。
:::

:::answer
【①全体を見る】対数の不等式。最初に真数条件：$x - 1 > 0$ かつ $x - 3 > 0$ より $x > 3$。
【②知識の利用】左辺を積にまとめ、右辺も底 $2$ の対数にする。$3 = \log_2 8$。
$$\log_2(x - 1)(x - 3) \le \log_2 8$$
底 $2$ は $1$ より大きいので、不等号の向きはそのまま。
【③部分を見る】
$$(x - 1)(x - 3) \le 8 \quad\Longrightarrow\quad x^2 - 4x - 5 \le 0 \quad\Longrightarrow\quad (x + 1)(x - 5) \le 0$$
よって $-1 \le x \le 5$。真数条件 $x > 3$ と合わせて
答え：[[$3 < x \le 5$]]
:::

:::exercise 発展
関数 $y = 4^x + 4^{-x} - 2(2^x + 2^{-x}) + 3$ の最小値と、そのときの $x$ の値を求めよ。
:::

:::answer
【①全体を見る】$4^x,\ 4^{-x},\ 2^x,\ 2^{-x}$ と4種類ある。底を $2$ にそろえると $4^x = (2^x)^2,\ 4^{-x} = (2^{-x})^2$。
【②知識の利用】$2^x + 2^{-x}$ がカタマリとして出ている。2乗すると $4^x + 4^{-x}$ が作れる。
【③部分を見る】$t = 2^x + 2^{-x}$ とおく。
$$t^2 = 4^x + 2 \cdot 2^x \cdot 2^{-x} + 4^{-x} = 4^x + 4^{-x} + 2$$
よって $4^x + 4^{-x} = t^2 - 2$。
$$y = t^2 - 2 - 2t + 3 = t^2 - 2t + 1 = (t - 1)^2$$
変域：$2^x > 0,\ 2^{-x} > 0$ で積 $2^x \cdot 2^{-x} = 1$ が一定なので、相加平均・相乗平均の関係より
$$t = 2^x + 2^{-x} \ge 2\sqrt{2^x \cdot 2^{-x}} = 2$$
等号は $2^x = 2^{-x}$、すなわち $x = 0$ のとき。
$t \ge 2$ で $y = (t - 1)^2$ は増加するので、$t = 2$ で最小値 $1$。
答え：[[$x = 0$ のとき最小値 $1$]]

【④工夫する】頂点 $t = 1$ は変域 $t \ge 2$ の外。変域を出さずに「最小値 0」と答えるのが典型的なミス。
:::

:::check ③までやり切れチェック
- 底がバラバラなら、まず底をそろえたか
- 対数が出てきたら、最初に真数条件を書いたか
- $2^x$ などのカタマリを $t$ とおき、直後に $t > 0$（など変域）を書いたか
- 二次方程式・不等式の解を、$t > 0$ や真数条件でふるいにかけたか
- 不等式で、底が $1$ より大きいか小さいかを確認したか
:::
