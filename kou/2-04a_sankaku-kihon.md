## 練習問題

:::exercise 基本
(1) $210^\circ$ を弧度法で、$\dfrac{5\pi}{4}$ を度数法で表せ。
(2) 半径 $6$、中心角 $\dfrac{2\pi}{3}$ のおうぎ形の弧の長さ $l$ と面積 $S$ を求めよ。
:::

:::answer
【①全体を見る】単位の変換とおうぎ形の計量。
【②知識の利用】$180^\circ = \pi$。おうぎ形は $l = r\theta$、$S = \dfrac{1}{2}r^2\theta$。
【③部分を見る】(1) $210^\circ = 210 \times \dfrac{\pi}{180} = \dfrac{7\pi}{6}$、$\dfrac{5\pi}{4} = \dfrac{5}{4} \times 180^\circ = 225^\circ$
(2) $l = 6 \times \dfrac{2\pi}{3} = 4\pi$、$S = \dfrac{1}{2} \times 6^2 \times \dfrac{2\pi}{3} = 12\pi$（$\dfrac{1}{2}lr = \dfrac{1}{2} \times 4\pi \times 6$ でも同じ）
答え：[[(1) $\dfrac{7\pi}{6}$、$225^\circ$　(2) $l = 4\pi$、$S = 12\pi$]]
:::

:::exercise 標準
関数 $y = 2\sin\left(2\theta - \dfrac{\pi}{3}\right)$ の周期と、とりうる値の範囲を求めよ。また、このグラフは $y = \sin\theta$ のグラフをどのように拡大・平行移動したものか答えよ。
:::

:::answer
【①全体を見る】基本形 $y = \sin\theta$ からの変形を読む。
【②知識の利用】$\theta$ の係数をくくる：$y = 2\sin 2\left(\theta - \dfrac{\pi}{6}\right)$。
【③部分を見る】係数ごとに読む。
- $\theta$ の係数 $2$：$\theta$ 軸方向に $\dfrac{1}{2}$ 倍 → 周期は $\dfrac{2\pi}{2} = \pi$
- 前の $2$：$y$ 軸方向に $2$ 倍 → $-2 \le y \le 2$
- $\theta - \dfrac{\pi}{6}$：$\theta$ 軸方向に $\dfrac{\pi}{6}$ 平行移動

答え：[[周期 $\pi$、$-2 \le y \le 2$。$y = \sin\theta$ を $\theta$ 軸方向に $\dfrac{1}{2}$ 倍、$y$ 軸方向に $2$ 倍し、$\theta$ 軸方向に $\dfrac{\pi}{6}$ 平行移動したもの]]

よくあるミス：くくらずに「$\dfrac{\pi}{3}$ 平行移動」と読む。
:::

:::exercise 発展
$0 \le \theta < 2\pi$ のとき、不等式 $2\cos^2\theta - \sin\theta - 1 \ge 0$ を解け。
:::

:::answer
【①全体を見る】sin と cos が混ざっている。1種類にそろえたい。
【②知識の利用】相互関係 $\cos^2\theta = 1 - \sin^2\theta$ で sin にそろえる。
$$2(1 - \sin^2\theta) - \sin\theta - 1 \ge 0 \quad\Longrightarrow\quad 2\sin^2\theta + \sin\theta - 1 \le 0$$
【③部分を見る】$\sin\theta$ をカタマリと見て因数分解。
$$(2\sin\theta - 1)(\sin\theta + 1) \le 0 \quad\Longrightarrow\quad -1 \le \sin\theta \le \frac{1}{2}$$
単位円で $y \le \dfrac{1}{2}$ の弧を読む（$y \ge -1$ はつねに成り立つ）。境目は $\theta = \dfrac{\pi}{6},\ \dfrac{5\pi}{6}$。
答え：[[$0 \le \theta \le \dfrac{\pi}{6},\ \dfrac{5\pi}{6} \le \theta < 2\pi$]]

【④工夫する】二次不等式に還元したあと、もう一度単位円に戻って弧を読む。弧が $\theta = 0$ をまたぐので2つに分かれる。
:::

:::check ③までやり切れチェック
- 角を弧度法で読み、範囲（$0 \le \theta < 2\pi$ など）を確認したか
- 単位円を描き、sin なら横線・cos なら縦線を引いたか
- 交点・弧を範囲内で全部拾ったか（範囲外の角は $2\pi$ を足して直したか）
- 弧が $\theta = 0$ をまたぐとき、範囲を2つに分けたか
- グラフの移動を読む前に、$\theta$ の係数をくくったか
:::
