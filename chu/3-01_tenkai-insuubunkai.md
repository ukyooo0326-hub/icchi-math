## 練習問題

:::exercise 基本
$3x^2 - 12$ を因数分解せよ。
:::

:::answer
【①全体を見る】両方の項に $3$ がある。共通因数でくくる。
$$3x^2 - 12 = 3(x^2 - 4)$$
【②知識の利用】カッコの中は $x^2 - 2^2$。2乗引く2乗の公式。
$$3(x^2-4) = 3(x+2)(x-2)$$
答え：[[$3(x+2)(x-2)$]]

よくあるミス：$3(x^2-4)$ で止める。くくった後も①から見直す。
:::

:::exercise 標準
$(a-b)^2 + 6(a-b) + 9$ を因数分解せよ。
:::

:::answer
【①全体を見る】3つの項すべてに入っている因数はない（$9$ に $a-b$ がない）。
【②知識の利用】このままでは公式の形に見えない。
【③部分を見る】$(a-b)$ が2回出てくる。$a - b = A$ とおく。
$$A^2 + 6A + 9$$
【②知識の利用（もう一度）】$A^2 + 2 \times 3 \times A + 3^2$ だから $(A+3)^2$。
元に戻して、答え：[[$(a-b+3)^2$]]
:::

:::exercise 発展
$(x^2 + 2x)^2 - 2(x^2 + 2x) - 3$ を因数分解せよ。
:::

:::answer
【③部分を見る】$x^2 + 2x = A$ とおく。
$$A^2 - 2A - 3 = (A-3)(A+1)$$
元に戻す。
$$(x^2 + 2x - 3)(x^2 + 2x + 1)$$
【①全体を見る（もう一度）】カッコの中も因数分解できないか見直す。
- $x^2 + 2x - 3$：足して $2$、かけて $-3$ → $3$ と $-1$ → $(x+3)(x-1)$
- $x^2 + 2x + 1 = (x+1)^2$

答え：[[$(x+3)(x-1)(x+1)^2$]]

元に戻したところで止めると不正解。>>41 の「これ以上分解できない形まで」を思い出す。
:::

:::check ③までやり切れチェック
- 式を見たら、まずゴール（積の形）と共通因数を確認したか
- 4つの公式の形と見比べたか
- 2回以上出てくるカタマリに丸をつけて、文字で置き換えたか
- 置き換えた文字を元に戻したか
- 答えのカッコの中を、もう一度①から見直したか
:::
