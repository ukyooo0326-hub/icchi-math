## 練習問題

:::exercise 基本
整式 $P(x) = x^3 - 2x^2 + 3x + 1$ を $x + 1$ で割ったときの余りを求めよ。
:::

:::answer
【①全体を見る】求めるのは余りだけ。商はいらない。
【②知識の利用】剰余の定理：$P(x)$ を $x - a$ で割った余りは $P(a)$。
【③部分を見る】$x + 1 = x - (-1)$ だから $a = -1$。
$$P(-1) = (-1)^3 - 2(-1)^2 + 3(-1) + 1 = -1 - 2 - 3 + 1 = -5$$
答え：[[$-5$]]

よくあるミス：$x + 1$ を見て $P(1)$ を計算する。「$x - a$」の形に直してから $a$ を読む。
:::

:::exercise 標準
2次方程式 $x^2 - 2x + 3 = 0$ の2つの解を $\alpha,\ \beta$ とするとき、$\alpha^2 + \beta^2$ と $\alpha^3 + \beta^3$ の値を求めよ。
:::

:::answer
【①全体を見る】解そのもの（虚数）を求めて代入するのはめんどくさい。$\alpha,\ \beta$ について対称な式であることに注目。
【②知識の利用】解と係数の関係より $\alpha + \beta = 2,\ \alpha\beta = 3$。
【③部分を見る】対称式は和と積で表せる。
$$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 4 - 6 = -2$$
$$\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = 8 - 18 = -10$$
答え：[[$\alpha^2 + \beta^2 = -2,\ \alpha^3 + \beta^3 = -10$]]

$\alpha^2 + \beta^2$ が負になって驚くかもしれないが、$\alpha,\ \beta$ は虚数（$D/4 = 1 - 3 < 0$）なので問題ない。
:::

:::exercise 発展
$a,\ b$ を実数とする。3次方程式 $x^3 + ax^2 + bx + 15 = 0$ が $1 + 2i$ を解にもつとき、$a,\ b$ の値と他の解を求めよ。
:::

:::answer
【①全体を見る】未知数は $a,\ b$ の2つ。「$1 + 2i$ が解」は「代入すると 0」という条件。
【②知識の利用】代入して、複素数の相等（実部と虚部がともに 0）を使う。
【③部分を見る】先に $1 + 2i$ の累乗を作っておく。
$$(1 + 2i)^2 = 1 + 4i + 4i^2 = -3 + 4i$$
$$(1 + 2i)^3 = (1 + 2i)(-3 + 4i) = -3 + 4i - 6i + 8i^2 = -11 - 2i$$
代入すると $(-11 - 2i) + a(-3 + 4i) + b(1 + 2i) + 15 = 0$。実部と虚部に分けて
$$(4 - 3a + b) + (-2 + 4a + 2b)i = 0$$
$a,\ b$ は実数だから $4 - 3a + b = 0$ かつ $-2 + 4a + 2b = 0$。連立して $a = 1,\ b = -1$。

【②知識の利用（もう一度）】$P(x) = x^3 + x^2 - x + 15$。因数定理で $P(-3) = -27 + 9 + 3 + 15 = 0$。
$$P(x) = (x + 3)(x^2 - 2x + 5)$$
$x^2 - 2x + 5 = 0$ を解くと $x = 1 \pm 2i$。
答え：[[$a = 1,\ b = -1$、他の解は $x = 1 - 2i,\ -3$]]

【④工夫する】実数係数の方程式では、$1 + 2i$ が解なら $1 - 2i$ も解になる。これを知っていれば、$1 \pm 2i$ を解にもつ $x^2 - 2x + 5$ で割り切れることから $a,\ b$ を出すこともできる。
:::

:::check ③までやり切れチェック
- 次数を確認し、「1次 × 2次」に分解するゴールを立てたか
- 定数項の約数を候補として、小さい順に代入したか
- 割り算の結果を展開して検算したか
- 残った2次方程式を複素数の範囲で解いたか（$D < 0$ でも「解なし」にしない）
- 解と係数の関係で、和と積を確かめたか
:::
