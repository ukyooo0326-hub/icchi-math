## 練習問題

:::exercise 基本
$x$ の値が $2$ 増加すると $y$ の値は $6$ 減少し、$x = 1$ のとき $y = 4$ である一次関数の式を求めよ。
:::

:::answer
【①全体を見る】式は $y = ax + b$。決めるのは $a$ と $b$。
【②知識の利用】変化の割合が傾き。$y$ は「減少」なので増加量は $-6$。
$$a = \frac{-6}{2} = -3$$
【③部分を見る】$y = -3x + b$ に $x = 1$、$y = 4$ を代入する。
$$4 = -3 + b$$
$$b = 7$$
答え：[[$y = -3x + 7$]]

よくあるミス：「6減少」を $+6$ のまま使って $a = 3$ にする。減少は負の増加量。
:::

:::exercise 標準
(1) 2点 $(-2,\ -1)$、$(2,\ 7)$ を通る直線の式を求めよ。
(2) 方程式 $3x + 2y = 8$ のグラフの傾きと切片を求めよ。また、このグラフと直線 $x = 2$ の交点の座標を求めよ。
:::

:::answer
(1)【①全体を見る】式は $y = ax + b$。2点から $a$ と $b$ を決める。
【②知識の利用】$(-2,\ -1)$ を「前」、$(2,\ 7)$ を「後」にして、変化の割合を求める。
$$a = \frac{7 - (-1)}{2 - (-2)} = \frac{8}{4} = 2$$
【③部分を見る】$y = 2x + b$ に $(-2,\ -1)$ を代入する。
$$-1 = -4 + b$$
$$b = 3$$
検算：$(2,\ 7)$ を代入すると $2 \times 2 + 3 = 7$。
答え：(1) [[$y = 2x + 3$]]

(2)【①全体を見る】ゴールは傾き・切片と、$x = 2$ との交点。
【②知識の利用】二元一次方程式は $y$ について解くと一次関数になる。
$$2y = -3x + 8$$
$$y = -\frac{3}{2}x + 4$$
傾きは $-\dfrac{3}{2}$、切片は $4$。
【③部分を見る】$x = 2$ は $y$ 軸に平行な直線。交点の $x$ 座標は $2$ に決まるので、代入する。
$$y = -\frac{3}{2} \times 2 + 4 = 1$$
答え：(2) 傾き $-\dfrac{3}{2}$、切片 $4$、交点 [[$(2,\ 1)$]]
:::

:::exercise 発展
直線 $\ell : y = 2x + 3$ と直線 $m : y = -x + 6$ の交点を P、$\ell$ と $y$ 軸の交点を A、$m$ と $y$ 軸の交点を B とする。△PAB の面積を求めよ（座標の1目もりを $1\,\text{cm}$ とする）。
:::

:::answer
【①全体を見る】ゴールは三角形の面積。底辺と高さがわかればよい。
【②知識の利用】交点 P は連立方程式で求める。
$$2x + 3 = -x + 6$$
$$3x = 3$$
$x = 1$、$y = 2 + 3 = 5$ より P$(1,\ 5)$。
A、B は切片なので A$(0,\ 3)$、B$(0,\ 6)$。
【③部分を見る】$y$ 軸上の AB を底辺とみる。AB $= 6 - 3 = 3$。高さは P から $y$ 軸までの距離で、P の $x$ 座標の $1$。
$$\frac{1}{2} \times 3 \times 1 = \frac{3}{2}$$
答え：[[$\dfrac{3}{2}\,\text{cm}^2$]]

（図：$y$ 軸上に A と B、その右側に P がある三角形）
:::
