## 練習問題

:::exercise 基本
(1) $\sqrt{75} - \sqrt{12}$ を計算せよ。
(2) $2\sqrt{7}$ と $3\sqrt{3}$ の大小を、不等号を使って表せ。
:::

:::answer
(1)【①全体を見る】√ の中が 75 と 12 でそろっていない。$a\sqrt{b}$ の形にしてからまとめる。
【②知識の利用】$\sqrt{a^2 b} = a\sqrt{b}$ を使う。
【③部分を見る】1個ずつ素因数分解する。
- $75 = 3 \times (5 \times 5)$ だから $\sqrt{75} = 5\sqrt{3}$
- $12 = (2 \times 2) \times 3$ だから $\sqrt{12} = 2\sqrt{3}$

$\sqrt{3}$ を文字とみて同類項をまとめる。
$$5\sqrt{3} - 2\sqrt{3} = 3\sqrt{3}$$
答え：[[$3\sqrt{3}$]]

よくあるミス：$\sqrt{75 - 12} = \sqrt{63}$ としてしまう。√ のひき算で中身はひけない。

(2)【①全体を見る】ゴールは大小。どちらも正の数。
【②知識の利用】正の数どうしなら、2乗して大きいほうが大きい。
【③部分を見る】それぞれ2乗する。$(2\sqrt{7})^2 = 4 \times 7 = 28$、$(3\sqrt{3})^2 = 9 \times 3 = 27$。$28 > 27$ なので
答え：[[$2\sqrt{7} > 3\sqrt{3}$]]

よくあるミス：外の数だけ見て「3 のほうが大きいから $3\sqrt{3}$ が大きい」とする。
:::

:::exercise 標準
$\sqrt{6} \times \sqrt{15} + \sqrt{40}$ を計算せよ。
:::

:::answer
【①全体を見る】かけ算とたし算がまざっている。かけ算を先にして、最後に $a\sqrt{b}$ の形でまとめる。
【②知識の利用】$\sqrt{a}\sqrt{b} = \sqrt{ab}$、$\sqrt{a^2 b} = a\sqrt{b}$。
【③部分を見る】かけ算の部分だけ見る。$6 \times 15$ を計算する前に素因数で書く。
$$\sqrt{6} \times \sqrt{15} = \sqrt{2 \times 3 \times 3 \times 5} = 3\sqrt{10}$$
次に $\sqrt{40}$ だけ見る。$40 = (2 \times 2) \times 2 \times 5$ だから $\sqrt{40} = 2\sqrt{10}$。
$$3\sqrt{10} + 2\sqrt{10} = 5\sqrt{10}$$
答え：[[$5\sqrt{10}$]]
:::

:::exercise 発展
$\dfrac{12}{\sqrt{6}} + (\sqrt{3} - \sqrt{2})^2$ を計算せよ。
:::

:::answer
【①全体を見る】「分数の項」と「2乗の項」の2つのたし算。1つずつ $a\sqrt{b}$ や整数の形にする。
【②知識の利用】2乗の項は乗法公式 $(x-a)^2 = x^2 - 2ax + a^2$ の形。
【③部分を見る】$(\sqrt{3} - \sqrt{2})^2$ だけ見る。$x = \sqrt{3}$、$a = \sqrt{2}$ として
$$(\sqrt{3})^2 - 2 \times \sqrt{2} \times \sqrt{3} + (\sqrt{2})^2 = 3 - 2\sqrt{6} + 2 = 5 - 2\sqrt{6}$$
【④工夫する】$\dfrac{12}{\sqrt{6}}$ は分母を有理化する。
$$\frac{12}{\sqrt{6}} = \frac{12\sqrt{6}}{6} = 2\sqrt{6}$$
合わせると $2\sqrt{6} + 5 - 2\sqrt{6} = 5$。

答え：[[$5$]]

√ が消えて整数になるのは、有理化と展開をそれぞれ最後までやり切ったから。途中で止めると気づけない。
:::

:::check ③までやり切れチェック
- ゴール「各項を $a\sqrt{b}$ の形にそろえる」を最初に確認したか
- √ の中の数を1個ずつ素因数分解して、ペアに丸をつけたか
- ペアが2組以上のとき、外に出た数を全部かけたか

- 分母に √ が残っていないか確認したか
- 大小を比べるとき、2乗して整数どうしで比べたか
:::
