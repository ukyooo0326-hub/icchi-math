## 練習問題

:::exercise 基本
方程式 $5x - 7 = 2x + 8$ を解け。
:::

:::answer
【①全体を見る】ゴールは $x = $（数）の形。分数・小数はない。
【②知識の利用】等式の性質（移項）で、$x$ の項を左辺、数の項を右辺に集める。
【③部分を見る】$2x$ を左辺へ、$-7$ を右辺へ移項する。
$$5x - 2x = 8 + 7$$
$$3x = 15$$
両辺を $3$ でわって、答え：[[$x = 5$]]

検算：左辺 $25 - 7 = 18$、右辺 $10 + 8 = 18$。
:::

:::exercise 標準
方程式 $0.2x - 0.5 = 0.7x + 1$ を解け。
:::

:::answer
【①全体を見る】ゴールは $x = $（数）の形。小数がウザい。
【②知識の利用】両辺に同じ数をかけてよい。
【③部分を見る】小数点を消すため、両辺に $10$ をかける。右辺の $1$ にもかける。
$$2x - 5 = 7x + 10$$
移項して
$$2x - 7x = 10 + 5$$
$$-5x = 15$$
両辺を $-5$ でわって、答え：[[$x = -3$]]

検算：左辺 $-0.6 - 0.5 = -1.1$、右辺 $-2.1 + 1 = -1.1$。
:::

:::exercise 発展
方程式 $\dfrac{2x-1}{3} - \dfrac{x-2}{4} = 1$ を解け。
:::

:::answer
【①全体を見る】ゴールは $x = $（数）の形。分数が2つある。
【②知識の利用】両辺に同じ数をかけて分母をはらう。
【③部分を見る】分母 $3$ と $4$ の最小公倍数 $12$ を、右辺の $1$ もふくめて両辺にかける。
$$4(2x - 1) - 3(x - 2) = 12$$
カッコをはずす。$-3 \times (-2) = +6$ に注意。
$$8x - 4 - 3x + 6 = 12$$
$$5x + 2 = 12$$
$$5x = 10$$
答え：[[$x = 2$]]

検算：左辺 $\frac{3}{3} - \frac{0}{4} = 1$、右辺 $1$。
よくあるミス：$-3(x-2)$ を $-3x - 6$ にする。分子はカッコつきのカタマリとして扱う。
:::

:::check ③までやり切れチェック
- ゴールが「$x = $（数）」だと確認したか
- 分母・小数点など「ウザい所」を特定したか
- 両辺の **すべての項** に同じ数をかけたか
- 移項で符号を変えたか（等式の性質で説明できるか）
- 解をもとの式に代入して検算したか
:::
