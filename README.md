# イッチと解く数学

5ch風スレの掛け合いで中高数学の「本質」を学ぶテキスト。
**中学生版**（中1→中3）と **高校生版**（数I→数A→数II→数B→数C／数III）を、学習指導要領の履修順に収録。

> 「めんどくさい」を、最高に合理的な思考のエネルギーに変える。

## 中身
- `chu/` 中学生版の原稿（1スレ＝1単元、内容が多い単元は Part2 スレに分割）
- `kou/` 高校生版の原稿
- `docs/curriculum.md` 目次（この表の順が掲載順）
- `docs/style-guide.md` 原稿の書き方（記法・構成・キャラ・品質基準）
- `.claude/agents/` 3人の専門家ペルソナ（`math-educator` / `meme-editor` / `ui-designer`）
- `tools/build.py` ビルドスクリプト、`tools/template.html` 閲覧用 HTML のテンプレート

## 各スレの構成
1. スレ本編：イッチが詰まる → 古参ニキが「どこがウザい？」と聞く → 4ステップで解体 → イッチがやらかす → 名無しがツッコむ → イッチが自力で類題を解く
2. このスレのテンプレ（まとめ）
3. 練習問題（基本・標準・発展）と解答。解答もすべて4ステップで書く
4. ③までやり切れチェック

## ビルド
```sh
python3 tools/build.py --check   # 記法チェック（警告ゼロが目標）
python3 tools/build.py           # dist/index.html を生成
```
`dist/index.html` はブラウザで開くだけで読める（数式は MathJax、フォントは Google Fonts を読み込む）。
赤シートボタンで赤字（定義・公式・答え）を隠せる。隠れた箇所はタップで1つずつ表示。
