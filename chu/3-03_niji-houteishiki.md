## 練習問題

:::exercise 基本
二次方程式 $x^2 = 6x$ を解け。
:::

:::answer
【①全体を見る】右辺の $6x$ を左辺に移項して「$= 0$」にする。両辺を $x$ で割ってはいけない。
$$x^2 - 6x = 0$$
【②知識の利用】共通因数 $x$ でくくると $AB = 0$ の形。
$$x(x - 6) = 0$$
$x = 0$ または $x - 6 = 0$。

答え：[[$x = 0,\ 6$]]

よくあるミス：$x$ で割って $x = 6$ だけを答える。
:::

:::exercise 標準
二次方程式 $x^2 + 6x + 2 = 0$ を、平方完成を使って解け。
:::

:::answer
【①全体を見る】右辺は 0。ゴールは「$x = $ 数」。
【②知識の利用】足して 6、かけて 2 になる整数はないので、因数分解は使えない。平方完成で「$(\ )^2 = $ 数」の形をめざす。
【③部分を見る】$x^2 + 6x$ の部分だけ見る。$x$ の係数 6 の半分の2乗は $3^2 = 9$。
$$x^2 + 6x = (x+3)^2 - 9$$
元の式に戻す。
$$(x+3)^2 - 9 + 2 = 0$$
$$(x+3)^2 = 7$$
平方根をとって $x + 3 = \pm\sqrt{7}$。

答え：[[$x = -3 \pm \sqrt{7}$]]

検算：解の公式でも $x = \dfrac{-6 \pm \sqrt{36 - 8}}{2} = \dfrac{-6 \pm 2\sqrt{7}}{2} = -3 \pm \sqrt{7}$ で一致する。
:::

:::exercise 発展
二次方程式 $2x^2 + 4x - 3 = 0$ を解け。
:::

:::answer
【①全体を見る】右辺は 0。$x^2$ の係数が 2 で、共通因数もない。
【②知識の利用】中3の因数分解の公式では分解できないので、解の公式を使う。
【③部分を見る】$a = 2$、$b = 4$、$c = -3$。
$$x = \frac{-4 \pm \sqrt{4^2 - 4 \times 2 \times (-3)}}{2 \times 2} = \frac{-4 \pm \sqrt{40}}{4}$$
$\sqrt{40} = 2\sqrt{10}$ なので
$$\frac{-4 \pm 2\sqrt{10}}{4} = \frac{-2 \pm \sqrt{10}}{2}$$
答え：[[$x = \dfrac{-2 \pm \sqrt{10}}{2}$]]

よくあるミス：約分で $-4$ だけ（または $2\sqrt{10}$ だけ）を割る。分子の **すべての項** を同じ数で割る。
:::

:::check ③までやり切れチェック
- 全部左に集めて「$= 0$」の形にしたか（文字で割っていないか）
- 平方根で解ける形 → 因数分解 → 解の公式、の順で試したか
- 平方根をとるときに $\pm$ をつけたか
- 解の公式で $a, b, c$ を符号ごとカッコに入れて代入したか
- √ の中を簡単にし、約分は分子のすべての項でしたか
- 文章題では、解が問題の条件（正の数・整数など）に合うか吟味したか
:::
