## 練習問題

:::exercise 基本
加法定理を用いて、$\sin 75^\circ$ の値を求めよ。
:::

:::answer
【①全体を見る】$75^\circ$ は三角比の表で覚えている角ではない。知っている角の和で表す。
【②知識の利用】$75^\circ = 45^\circ + 30^\circ$。加法定理 $\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$。
$$\sin 75^\circ = \sin 45^\circ\cos 30^\circ + \cos 45^\circ\sin 30^\circ = \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2}$$
$$= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4}$$
答え：[[$\dfrac{\sqrt{6} + \sqrt{2}}{4}$]]
:::

:::exercise 標準
$0 \le \theta < 2\pi$ のとき、関数 $y = \sin\theta + \sqrt{3}\cos\theta$ の最大値と最小値、およびそのときの $\theta$ の値を求めよ。
:::

:::answer
【①全体を見る】角は $\theta$ でそろっているが、sin と cos が1乗で並んでいる。2倍角ではそろえられない。
【②知識の利用】合成。$a = 1,\ b = \sqrt{3}$ で $\sqrt{a^2 + b^2} = 2$。$\cos\alpha = \dfrac{1}{2},\ \sin\alpha = \dfrac{\sqrt{3}}{2}$ より $\alpha = \dfrac{\pi}{3}$。
$$y = 2\sin\left(\theta + \frac{\pi}{3}\right)$$
【③部分を見る】$\theta + \dfrac{\pi}{3}$ をカタマリと見て、その変域を出す。$0 \le \theta < 2\pi$ より
$$\frac{\pi}{3} \le \theta + \frac{\pi}{3} < \frac{7\pi}{3}$$
この範囲で $\sin$ は $1$ から $-1$ までとる。
- 最大：$\theta + \dfrac{\pi}{3} = \dfrac{\pi}{2}$ → $\theta = \dfrac{\pi}{6}$
- 最小：$\theta + \dfrac{\pi}{3} = \dfrac{3\pi}{2}$ → $\theta = \dfrac{7\pi}{6}$

答え：[[最大値 $2$（$\theta = \dfrac{\pi}{6}$）、最小値 $-2$（$\theta = \dfrac{7\pi}{6}$）]]
:::

:::exercise 発展
$0 \le \theta < 2\pi$ のとき、関数 $y = \sin 2\theta + \sin\theta + \cos\theta$ の最大値と最小値を求めよ。
:::

:::answer
【①全体を見る】角が $2\theta$ と $\theta$ でバラバラ。$\sin 2\theta$ を2倍角で直しても $2\sin\theta\cos\theta$ で、sin・cos 1種類にはそろわない。
【②知識の利用】$\sin\theta + \cos\theta$ を2乗すると $\sin\theta\cos\theta$ が出てくる。
【③部分を見る】$t = \sin\theta + \cos\theta$ とおく。
$$t^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = 1 + \sin 2\theta$$
よって $\sin 2\theta = t^2 - 1$。
変域：合成より $t = \sqrt{2}\sin\left(\theta + \dfrac{\pi}{4}\right)$ だから $-\sqrt{2} \le t \le \sqrt{2}$。
$$y = t^2 - 1 + t = \left(t + \frac{1}{2}\right)^2 - \frac{5}{4}$$
頂点 $t = -\dfrac{1}{2}$ は変域内 → 最小値 $-\dfrac{5}{4}$。
端は $t = \sqrt{2}$ で $y = 2 + \sqrt{2} - 1 = 1 + \sqrt{2}$、$t = -\sqrt{2}$ で $y = 2 - \sqrt{2} - 1 = 1 - \sqrt{2}$。大きいほうが最大値。
答え：[[最大値 $1 + \sqrt{2}$、最小値 $-\dfrac{5}{4}$]]

【④工夫する】「$\sin\theta + \cos\theta$ と $\sin\theta\cos\theta$ が同居していたら、和を $t$ とおく」は入試の定番。2乗すれば積が出る、という関係がヒント。
:::
