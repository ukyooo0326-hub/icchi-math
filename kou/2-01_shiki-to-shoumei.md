## 練習問題

:::exercise 基本
$(2x - 1)^6$ の展開式における $x^4$ の係数を求めよ。
:::

:::answer
【①全体を見る】6個のカッコ $(2x - 1)$ の積。全部展開するのはめんどくさいので、$x^4$ の項だけ狙う。
【②知識の利用】二項定理の一般項は ${}_6\mathrm{C}_r (2x)^{6-r}(-1)^r$。
【③部分を見る】$x^4$ になるのは $6 - r = 4$、つまり $r = 2$ のとき。
$${}_6\mathrm{C}_2 \cdot (2x)^4 \cdot (-1)^2 = 15 \cdot 16x^4 \cdot 1 = 240x^4$$
答え：[[$240$]]

よくあるミス：$(2x)^4$ の $2^4 = 16$ をかけ忘れて $15$ と答える。係数は「カッコの中の数ごと」4乗する。
:::

:::exercise 標準
等式 $x^2 + 3x - 1 = a(x - 1)^2 + b(x - 1) + c$ が $x$ についての恒等式となるように、定数 $a,\ b,\ c$ の値を定めよ。
:::

:::answer
【①全体を見る】恒等式＝どんな $x$ でも成り立つ式。ゴールは $a,\ b,\ c$ の値。
【②知識の利用】恒等式なら両辺の同じ次数の係数が等しい（係数比較）。右辺を展開する。
$$a(x - 1)^2 + b(x - 1) + c = ax^2 + (-2a + b)x + (a - b + c)$$
係数を比較して
$$a = 1, \quad -2a + b = 3, \quad a - b + c = -1$$
【③部分を見る】上から順に1文字ずつ決まる。$a = 1$ → $b = 5$ → $c = 3$。
答え：[[$a = 1,\ b = 5,\ c = 3$]]

別解：$x - 1 = t$（$x = t + 1$）とおくと左辺は $(t + 1)^2 + 3(t + 1) - 1 = t^2 + 5t + 3$。右辺 $at^2 + bt + c$ と見比べても同じ結果。
:::

:::exercise 発展
$x > 1$ のとき、$x + \dfrac{4}{x - 1}$ の最小値と、そのときの $x$ の値を求めよ。
:::

:::answer
【①全体を見る】和の最小値。相加平均・相乗平均の関係が使えそう。
【②知識の利用】相加相乗は「積が一定」のときに使う。しかし $x \cdot \dfrac{4}{x-1}$ は一定ではない。このままでは使えない。
【③部分を見る】分母の $x - 1$ をカタマリと見る。$x = (x - 1) + 1$ と分ける。
$$x + \frac{4}{x - 1} = (x - 1) + \frac{4}{x - 1} + 1$$
$x > 1$ より $x - 1 > 0$。$(x - 1) \cdot \dfrac{4}{x-1} = 4$ で積が一定になった。
$$(x - 1) + \frac{4}{x - 1} + 1 \ge 2\sqrt{4} + 1 = 5$$
等号は $x - 1 = \dfrac{4}{x - 1}$ → $(x - 1)^2 = 4$ → $x - 1 > 0$ より $x - 1 = 2$、すなわち $x = 3$。
答え：[[$x = 3$ のとき最小値 $5$]]

【④工夫する】「積を一定にしたい」というゴールから逆算して、分母と同じカタマリを作った。
:::

- 不等式を見たら、まず「左辺 − 右辺」を作ったか
- 差を文字ごとに分けて平方完成し、2乗の和にしたか（2文字なら片方を定数扱い）
- 等号成立条件を書いたか
- 相加相乗を使う前に「積が一定か」を確認したか
