## 練習問題

:::exercise 基本
2点 $\mathrm{A}(1,\ 2)$、$\mathrm{B}(4,\ 6)$ について、$\overrightarrow{AB}$ を成分で表し、$|\overrightarrow{AB}|$ を求めよ。
:::

:::answer
【①全体を見る】ゴールは $\overrightarrow{AB}$ の成分と大きさ。
【②知識の利用】$\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$（後ろ − 前）。大きさは $\sqrt{a_1^2 + a_2^2}$。
【③部分を見る】成分ごとに引く。
$$\overrightarrow{AB} = (4 - 1,\ 6 - 2) = (3,\ 4)$$
$$|\overrightarrow{AB}| = \sqrt{3^2 + 4^2} = 5$$
答え：[[$\overrightarrow{AB} = (3,\ 4)$、$|\overrightarrow{AB}| = 5$]]

よくあるミス：前 − 後ろで $(-3,\ -4)$ にする。$\overrightarrow{AB}$ は B（終点）から A（始点）を引く。
:::

:::exercise 標準
$\vec{a} = (1,\ -3)$、$\vec{b} = (2,\ 4)$ のなす角 $\theta$（$0^\circ \leqq \theta \leqq 180^\circ$）を求めよ。
:::

:::answer
【①全体を見る】ゴールはなす角。$\cos\theta$ を出せばよい。
【②知識の利用】$\cos\theta = \dfrac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$。
【③部分を見る】内積と大きさを別々に計算する。
$\vec{a} \cdot \vec{b} = 1 \times 2 + (-3) \times 4 = -10$
$|\vec{a}| = \sqrt{1 + 9} = \sqrt{10}$、$|\vec{b}| = \sqrt{4 + 16} = 2\sqrt{5}$
$$\cos\theta = \frac{-10}{\sqrt{10} \cdot 2\sqrt{5}} = \frac{-10}{10\sqrt{2}} = -\frac{1}{\sqrt{2}}$$
答え：[[$\theta = 135^\circ$]]

内積が負なら $\theta$ は鈍角。符号で先に見当をつけられる。
:::

:::exercise 発展
$\vec{a} = (3,\ 4)$ に垂直な単位ベクトルを求めよ。
:::

:::answer
【①全体を見る】求めるベクトルを $\vec{e} = (x,\ y)$ とおく。条件は「$\vec{a}$ に垂直」と「大きさ 1」の2つ。
【②知識の利用】垂直は内積 $0$、単位ベクトルは $|\vec{e}| = 1$。
【③部分を見る】2つの条件をそれぞれ式にする。
$$3x + 4y = 0, \qquad x^2 + y^2 = 1$$
1つ目から $x = -\dfrac{4}{3}y$。2つ目に代入して $\dfrac{16}{9}y^2 + y^2 = 1$、$y^2 = \dfrac{9}{25}$、$y = \pm\dfrac{3}{5}$。
$y = \dfrac{3}{5}$ のとき $x = -\dfrac{4}{5}$、$y = -\dfrac{3}{5}$ のとき $x = \dfrac{4}{5}$。
答え：[[$\left(\dfrac{4}{5},\ -\dfrac{3}{5}\right)$、$\left(-\dfrac{4}{5},\ \dfrac{3}{5}\right)$]]

【④工夫する】$(a_1,\ a_2)$ に垂直なベクトルは $(a_2,\ -a_1)$ がすぐ見つかる（内積が $a_1a_2 - a_2a_1 = 0$）。$(4,\ -3)$ を大きさ $5$ で割れば検算になる。向きは2つあることを忘れない。
:::

:::check ③までやり切れチェック
- ベクトルを成分（数の組）に直してから計算したか
- $\overrightarrow{AB}$ を「後ろ − 前」で計算したか
- 内積を計算したとき、最後に足して1つの数にしたか
- なす角は、内積と大きさを別々に出してから $\cos\theta$ にしたか
- 垂直は内積 $0$、平行は $\vec{b} = k\vec{a}$ と使い分けたか
:::
