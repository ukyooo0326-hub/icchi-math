## 練習問題

:::exercise 基本
比例式 $(x - 2) : 6 = 4 : 3$ を解け。
:::

:::answer
【①全体を見る】ゴールは $x$ の値。比例式の形。
【②知識の利用】$a : b = c : d$ ならば $ad = bc$。
【③部分を見る】外側は $(x - 2)$ と $3$、内側は $6$ と $4$。
$$3(x - 2) = 24$$
$$3x - 6 = 24$$
$$3x = 30$$
答え：[[$x = 10$]]

確かめ：$8 : 6$ と $4 : 3$ は、比の値がどちらも $\dfrac{4}{3}$。
:::

:::exercise 標準
画用紙を生徒に配る。1人に3枚ずつ配ると14枚余り、5枚ずつ配ると6枚足りない。生徒の人数と画用紙の枚数を求めよ。
:::

:::answer
【①全体を見る】ゴールは人数と枚数。等しい関係を1本見つける。
【②知識の利用】同じもの（画用紙の枚数）を2通りに表して ＝ でつなぐ。
【③部分を見る】生徒を $x$ 人とする。
- 3枚ずつで14枚余る → 枚数は $3x + 14$
- 5枚ずつで6枚足りない → 必要な $5x$ 枚より6枚少ない → 枚数は $5x - 6$

$$3x + 14 = 5x - 6$$
$$-2x = -20,\quad x = 10$$
枚数は $3 \times 10 + 14 = 44$。吟味：5枚ずつなら50枚必要で、$50 - 44 = 6$ 枚足りない。合う。

答え：[[生徒10人、画用紙44枚]]
:::

:::exercise 発展
妹が家を出て、分速 $70\,\text{m}$ で $2.1\,\text{km}$ 離れた図書館に向かった。その12分後に姉が自転車で、分速 $210\,\text{m}$ で同じ道を追いかけた。姉は出発して何分後に妹に追いつくか。また、図書館に着くまでに追いつけるか。
:::

:::answer
【①全体を見る】ゴールは追いつくまでの時間と、図書館の手前かどうか。
【②知識の利用】道のり＝速さ×時間。追いつく＝家から進んだ道のりが等しい。
【③部分を見る】姉が出発して $x$ 分後に追いつくとする。妹は $(x + 12)$ 分歩いている。
$$210x = 70(x + 12)$$
$$210x = 70x + 840$$
$$140x = 840,\quad x = 6$$
吟味：6分後の地点は家から $210 \times 6 = 1260\,\text{m}$。図書館までは $2.1\,\text{km} = 2100\,\text{m}$ なので、その手前。

答え：[[6分後に追いつく。図書館に着くまでに追いつける]]
:::

:::check ③までやり切れチェック
- ゴール（求めるもの）を確認し、何を $x$ にするか決めたか
- 文章を1文ずつ区切って、数量を $x$ で表したか
- 同じものを2通りに表して、等しい関係を1本つくったか
- 「余る・足りない」の符号を、どっちが多いかで決めたか
- 解が問題の場面に合っているか（人数が自然数か、道のりを超えていないか）吟味したか
:::
