:::point 文字式の表し方
- かけ算の記号 $\times$ は省く：$3 \times x = 3x$
- 数は文字の前に書く：$x \times 3 = 3x$（$x3$ とは書かない）
- $1 \times x$ は $x$ と書く（$1x$ とは書かない）
- わり算は分数の形で書く：$x \div 2 = \dfrac{x}{2}$
:::

## 練習問題

:::exercise 基本
1本 $a$ 円の鉛筆を5本と、1冊 $b$ 円のノートを2冊買ったときの代金の合計を、文字式で表せ。
:::

:::answer
【①全体を見る】ゴールは代金を $a$、$b$ を使った式で表すこと。
【②知識の利用】代金＝1個の値段 × 個数。文字式では $\times$ を省き、数を前に書く。
【③部分を見る】鉛筆の代金とノートの代金に分ける。
- 鉛筆：$a \times 5 = 5a$（円）
- ノート：$b \times 2 = 2b$（円）

答え：[[$5a + 2b$（円）]]

確かめ：$a = 100$、$b = 150$ なら $500 + 300 = 800$ 円。実際の買い物と一致する。
:::

:::exercise 標準
$2(3x - 1) - 3(x - 4)$ を計算せよ。
:::

:::answer
【①全体を見る】ゴールは式をいちばん簡単な一次式にすること。
【②知識の利用】分配法則でカッコをはずし、文字の項・数の項をそれぞれまとめる。
【③部分を見る】カッコを1つずつはずす。2つ目は $-3$ ごとかけるのがポイント。
$$2(3x-1) = 6x - 2$$
$$-3(x-4) = -3x + 12$$
まとめると
$$6x - 2 - 3x + 12 = 3x + 10$$
答え：[[$3x + 10$]]

よくあるミス：$-3(x-4)$ を $-3x - 12$ にする。$-3 \times (-4) = +12$。
:::

:::exercise 発展
碁石を正方形の形に並べる。1辺に $n$ 個ずつ並べるとき（ただし $n \geqq 2$）、碁石は全部で何個か。$n$ を使った式で表せ。
（図：1辺に4個ずつ、正方形のふちに碁石を並べたようす）
:::

:::answer
【①全体を見る】ゴールは個数を $n$ の式で表すこと。
【②知識の利用】「$n$ 個 × 4辺 $= 4n$」と考えたくなるが、角の碁石は2つの辺で共有している。
【③部分を見る】重ならないパーツに分ける。各辺から「最後の1個（次の辺の角）」を除いた $(n-1)$ 個ずつで4組に分けると、ちょうど1回ずつ数えられる。
$$4(n - 1) = 4n - 4$$
答え：[[$4n - 4$（個）]]（$4(n-1)$ でもよい）

確かめ：$n = 4$ のとき $4 \times 4 - 4 = 12$ 個。図で数えても12個。
$4n$ と答えるのは、マッチ棒の $4x$ と同じ「共有部分の二重カウント」。
:::

:::check ③までやり切れチェック
- ゴールが「数」ではなく「式」だと確認したか
- 文字を「まだ決めていない数」と読みかえたか
- 図や数量を、数えられるパーツに分けたか
- 共有している部分を二重に数えていないか確認したか
- できた式に小さい数を代入して、実物と一致するか確かめたか
:::
