:::point このスレのテンプレ
**図形と方程式は「翻訳」**
1. 【①全体を見る】図形の条件（共有点・接する・軌跡・領域）を、ゴールとなる **式** に言い換える

絵はイメージ用。答えは式で出す。点と直線の距離は **絶対値を外さない**。
:::

## 練習問題

:::exercise 基本
点 $(1,\ 2)$ と直線 $3x + 4y - 1 = 0$ の距離を求めよ。
:::

:::answer
【①全体を見る】点と直線の距離。直線はすでに $ax + by + c = 0$ の形。
【②知識の利用】点と直線の距離の公式に $a = 3,\ b = 4,\ c = -1,\ (x_1,\ y_1) = (1,\ 2)$ を代入。
$$d = \frac{|3 \cdot 1 + 4 \cdot 2 - 1|}{\sqrt{3^2 + 4^2}} = \frac{|10|}{5} = 2$$
答え：[[$2$]]
:::

:::exercise 標準
円 $x^2 + y^2 - 4x + 2y - 4 = 0$ の中心と半径を求めよ。また、この円と直線 $y = x + k$ が接するときの定数 $k$ の値を求めよ。
:::

:::answer
【①全体を見る】前半は円の式を「中心と半径が読める形」にする。後半は「接する」を式に翻訳する。
【②知識の利用】$x,\ y$ それぞれ平方完成する。
$$(x - 2)^2 - 4 + (y + 1)^2 - 1 - 4 = 0 \quad\Longrightarrow\quad (x - 2)^2 + (y + 1)^2 = 9$$
中心 $(2,\ -1)$、半径 $3$。
【③部分を見る】接する ⟺ 中心と直線の距離 $=$ 半径。直線を $x - y + k = 0$ に直す。
$$\frac{|2 - (-1) + k|}{\sqrt{1^2 + (-1)^2}} = 3 \quad\Longrightarrow\quad |k + 3| = 3\sqrt{2}$$
$k + 3 = \pm 3\sqrt{2}$ より $k = -3 \pm 3\sqrt{2}$。
答え：[[中心 $(2,\ -1)$、半径 $3$／$k = -3 \pm 3\sqrt{2}$]]

絶対値を外すときに $\pm$ を落とすと、接線が1本しか出てこない。直線 $y = x + k$ を上下に動かすと、円に接するのは2回ある。
:::

:::exercise 発展
実数 $x,\ y$ が $x^2 + y^2 \le 2$ を満たすとき、$x + y$ の最大値と最小値を求めよ。また、そのときの $x,\ y$ の値を求めよ。
:::

:::answer
【①全体を見る】条件 $x^2 + y^2 \le 2$ は、中心 $(0,\ 0)$、半径 $\sqrt{2}$ の円の周と内部（領域）。
【②知識の利用】$x + y$ のとり得る値を調べるので、$x + y = k$ とおく。
【③部分を見る】$x + y = k$ は傾き $-1$ の直線 $y = -x + k$。「$k$ をとり得る」⟺「この直線が領域と共有点をもつ」。
円の中心と直線 $x + y - k = 0$ の距離が半径以下になればよい。
$$\frac{|-k|}{\sqrt{2}} \le \sqrt{2} \quad\Longrightarrow\quad |k| \le 2 \quad\Longrightarrow\quad -2 \le k \le 2$$
【④工夫する】最大・最小は直線が円に **接する** とき。接点は中心から直線に下ろした垂線の足で、直線 $y = x$ 上にある。
$k = 2$ のとき $x = y$ かつ $x + y = 2$ より $(1,\ 1)$。$k = -2$ のとき $(-1,\ -1)$。
答え：[[最大値 $2$（$x = y = 1$）、最小値 $-2$（$x = y = -1$）]]

（図：円 $x^2 + y^2 = 2$ と、上下に平行移動する直線 $x + y = k$。上端・下端で円に接する）
:::

:::check ③までやり切れチェック
- 図形の条件（共有点・接する・軌跡・領域）を式に言い換えたか
- 円が出てきたら、中心と半径を読める形に平方完成したか
- 直線を $ax + by + c = 0$ に直してから距離の公式に代入したか
- 距離の絶対値を外すとき、$\pm$ の両方を残したか
- 軌跡では点を $(x,\ y)$ とおき、距離の条件は2乗してから計算したか
:::
