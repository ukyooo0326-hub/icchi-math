## 練習問題

:::exercise 基本
全体集合を $U = \{1, 2, 3, \cdots, 10\}$ とし、$A = \{x \mid x \text{ は偶数}\}$、$B = \{x \mid x \text{ は } 3 \text{ の倍数}\}$ とする（$x \in U$）。
(1) $\overline{A} \cap B$ を求めよ。
(2) $\overline{A \cup B}$ を求めよ。
:::

:::answer
【①全体を見る】要素が有限個なので、全部書き出せる。ゴールは要素の列挙。
【②知識の利用】補集合は「$U$ のうち入らないもの」。ド・モルガンの法則 $\overline{A \cup B} = \overline{A} \cap \overline{B}$。
【③部分を見る】まず $A$, $B$ を1つずつ書き出す。
- $A = \{2, 4, 6, 8, 10\}$、$B = \{3, 6, 9\}$
- $\overline{A} = \{1, 3, 5, 7, 9\}$

(1) $\overline{A}$ と $B$ の両方に入るもの。答え：[[$\{3, 9\}$]]

(2) $A \cup B = \{2, 3, 4, 6, 8, 9, 10\}$ なので、その補集合。答え：[[$\{1, 5, 7\}$]]

検算：$\overline{B} = \{1, 2, 4, 5, 7, 8, 10\}$ で、$\overline{A} \cap \overline{B} = \{1, 5, 7\}$。ド・モルガンの法則どおり一致する。
:::

:::exercise 標準
$x$, $y$ は実数とする。次の［　］に「必要条件だが十分条件ではない」「十分条件だが必要条件ではない」「必要十分条件」「必要条件でも十分条件でもない」のうち適するものを入れよ。
(1) $x^2 + y^2 = 0$ は $x = 0$ であるための［　］
(2) 「$x + y > 0$ かつ $xy > 0$」は「$x > 0$ かつ $y > 0$」であるための［　］
:::

:::answer
(1)
【①全体を見る】$p$：$x^2 + y^2 = 0$、$q$：$x = 0$。2方向の真偽を調べる。
【②知識の利用】真なら理由、偽なら反例1個。実数の2乗は $0$ 以上。
【③部分を見る】
- $p \Rightarrow q$：$x^2 \ge 0$、$y^2 \ge 0$ で和が $0$ なので $x^2 = y^2 = 0$。よって $x = 0$。**真**
- $q \Rightarrow p$：反例 $x = 0$, $y = 1$（$x^2 + y^2 = 1$）。**偽**

真なのは $p \Rightarrow q$ だけ。答え：[[十分条件だが必要条件ではない]]

(2)
【①全体を見る】$p$：$x + y > 0$ かつ $xy > 0$、$q$：$x > 0$ かつ $y > 0$。
【③部分を見る】
- $q \Rightarrow p$：正の数どうしの和も積も正。**真**
- $p \Rightarrow q$：$xy > 0$ より $x$, $y$ は同符号。両方負なら $x + y < 0$ となり $x + y > 0$ に反する。よって両方正。**真**

両方真なので、答え：[[必要十分条件]]

$p \Rightarrow q$ で反例が見つからないときは、場合分け（両方正／両方負）で「本当にない」ことを示す。
:::

:::exercise 発展
(1) 整数 $n$ について、「$n^2$ が $3$ の倍数ならば、$n$ は $3$ の倍数である」ことを証明せよ。
(2) (1) を用いて、$\sqrt{3}$ が無理数であることを証明せよ。
:::

:::answer
(1)
【①全体を見る】$n^2$ の情報から $n$ に戻る向きの命題。直接は示しにくい。
【④工夫する】対偶「$n$ が $3$ の倍数でないならば、$n^2$ は $3$ の倍数でない」を示す。
【③部分を見る】$3$ の倍数でない整数は、$k$ を整数として $n = 3k + 1$ または $n = 3k + 2$ と表せる。場合分けする。
$$(3k+1)^2 = 9k^2 + 6k + 1 = 3(3k^2 + 2k) + 1$$
$$(3k+2)^2 = 9k^2 + 12k + 4 = 3(3k^2 + 4k + 1) + 1$$
どちらも $3$ で割ると $1$ 余るので、$3$ の倍数でない。対偶が真なので、[[もとの命題も真]]。

(2)
【①全体を見る】「無理数である」＝「有理数でない」。否定の形なので直接は示しにくい。
【④工夫する】背理法。$\sqrt{3}$ が有理数であると仮定する。
【③部分を見る】1以外に正の公約数をもたない自然数 $m$, $n$ を用いて $\sqrt{3} = \dfrac{m}{n}$ と表せる。両辺を2乗して分母をはらうと
$$m^2 = 3n^2$$
- $m^2$ は $3$ の倍数なので、(1) より $m$ は $3$ の倍数。$m = 3l$（$l$ は自然数）とおく。
- 代入して $9l^2 = 3n^2$、つまり $n^2 = 3l^2$。$n^2$ も $3$ の倍数なので、(1) より $n$ も $3$ の倍数。

$m$, $n$ がともに $3$ を公約数にもつので、仮定に矛盾する。よって [[$\sqrt{3}$ は無理数]]。

(1) を「道具」として2回使うのがポイント。前の小問は次の小問の②になる。
:::
