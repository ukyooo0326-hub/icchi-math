## 練習問題

:::exercise 基本
ユークリッドの互除法を用いて、391 と 299 の最大公約数を求めよ。
:::

:::answer
【①全体を見る】ゴールは最大公約数。数が大きく、素因数分解はすぐには見えない。
【②知識の利用】互除法：大きい方を小さい方で割り、余りで割り続ける。
$$391 = 299 \times 1 + 92$$
$$299 = 92 \times 3 + 23$$
$$92 = 23 \times 4$$
割り切れたときの割る数が最大公約数。
答え：[[23]]

検算：$391 = 23 \times 17$、$299 = 23 \times 13$ で、17 と 13 は互いに素。
:::

:::exercise 標準
(1) 整数 $n$ について、$n^2$ を 4 で割った余りは 0 または 1 であることを示せ。
(2) $x^2 + y^2 = 2027$ を満たす整数 $x$、$y$ は存在しないことを示せ。
:::

:::answer
【①全体を見る】(2) は「存在しない」の証明。無限個の整数を全部調べることはできないので、余りで分類する。
【②知識の利用】2乗の余りは、元の数の偶奇で決まる。
【③部分を見る】(1) $n$ を偶数・奇数に分ける。$m$ を整数とする。
- $n = 2m$ のとき：$n^2 = 4m^2$ で余り $0$
- $n = 2m + 1$ のとき：$n^2 = 4m^2 + 4m + 1 = 4(m^2 + m) + 1$ で余り $1$

よって $n^2$ を 4 で割った余りは [[0 または 1]]。

(2) (1) より $x^2 + y^2$ を 4 で割った余りは $0 + 0$、$0 + 1$、$1 + 1$ のどれかで、$0$、$1$、$2$ のいずれか。
一方 $2027 = 4 \times 506 + 3$ で、4 で割った余りは $3$。
余りが一致しないので、[[$x^2 + y^2 = 2027$ を満たす整数は存在しない]]。
:::

:::exercise 発展
$xy - 2x - 3y = 1$ を満たす正の整数 $x$、$y$ の組をすべて求めよ。
:::

:::answer
【①全体を見る】$xy$ の項があるので一次不定方程式ではない。「積＝整数」の形を目指す。
【②知識の利用】$xy - 2x - 3y$ は $(x - 3)(y - 2) = xy - 2x - 3y + 6$ の一部。
【④工夫する】両辺に $6$ を足して積の形にする。$(x-3)(y-2)$ を展開した形から逆算すると思いつける。
$$(x - 3)(y - 2) = 7$$
【③部分を見る】$x$、$y$ は正の整数なので $x - 3 \geqq -2$、$y - 2 \geqq -1$。
7 の約数の組 $(1, 7)$、$(7, 1)$、$(-1, -7)$、$(-7, -1)$ のうち、条件を満たすのは
- $x - 3 = 1$、$y - 2 = 7$ → $(x, y) = (4, 9)$
- $x - 3 = 7$、$y - 2 = 1$ → $(x, y) = (10, 3)$

$(-1, -7)$ は $y - 2 = -7 < -1$、$(-7, -1)$ は $x - 3 = -7 < -2$ なので不適。
答え：[[$(x, y) = (4, 9), (10, 3)$]]

検算：$4 \times 9 - 8 - 27 = 1$、$10 \times 3 - 20 - 9 = 1$。
:::
