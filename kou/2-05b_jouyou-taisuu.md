## 練習問題

:::exercise 基本
$\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$ とする。$6^{20}$ は何桁の数か。また、最高位の数字を求めよ。
:::

:::answer
【①全体を見る】ゴールは桁数と最高位。常用対数をとる。
【②知識の利用】$\log_{10} 6 = \log_{10} 2 + \log_{10} 3 = 0.7781$ より
$$\log_{10} 6^{20} = 20 \times 0.7781 = 15.562$$
【③部分を見る】整数部分：$15 \le 15.562 < 16$ より $10^{15} \le 6^{20} < 10^{16}$ で16桁。
小数部分：$\log_{10} 3 = 0.4771 < 0.562 < 0.6020 = \log_{10} 4$（$\log_{10} 4 = 2\log_{10} 2$）より $3 < 10^{0.562} < 4$。
答え：[[16 桁、最高位の数字は $3$]]
:::

:::exercise 標準
$\log_{10} 3 = 0.4771$ とする。$(0.3)^{20}$ を小数で表したとき、小数第何位に初めて0でない数字が現れるか。
:::

:::answer
【①全体を見る】小さな数の「小数第何位」。常用対数をとって負の数を読む。
【②知識の利用】$\log_{10} 0.3 = \log_{10} \dfrac{3}{10} = \log_{10} 3 - 1 = -0.5229$
$$\log_{10} (0.3)^{20} = 20 \times (-0.5229) = -10.458$$
【③部分を見る】$-11 \le -10.458 < -10$ より $10^{-11} \le (0.3)^{20} < 10^{-10}$。
$10^{-11}$ 以上 $10^{-10}$ 未満なので、小数第11位に初めて0でない数字が現れる。
答え：[[小数第 $11$ 位]]

よくあるミス：$-10.458$ を見て「第10位」と答える。$10^{-10}$ より小さい数なので、もう1つ右になる。
:::

:::exercise 発展
ある町の人口は毎年 $20\%$ ずつ増えている。人口が初めて現在の $10$ 倍を超えるのは何年後か。ただし $\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$ とする。
:::

:::answer
【①全体を見る】$n$ 年後の人口は現在の $1.2^n$ 倍。$1.2^n > 10$ となる最小の整数 $n$ を求める。
【②知識の利用】両辺の常用対数をとる（底 $10 > 1$ なので向きはそのまま）。$n\log_{10} 1.2 > 1$。
【③部分を見る】$\log_{10} 1.2$ を知っている値で表す。$1.2 = \dfrac{12}{10} = \dfrac{2^2 \times 3}{10}$ より
$$\log_{10} 1.2 = 2\log_{10} 2 + \log_{10} 3 - 1 = 0.6020 + 0.4771 - 1 = 0.0791$$
$$n > \frac{1}{0.0791} = 12.6\cdots$$
答え：[[$13$ 年後]]

【④工夫する】$1.2$ のような小数は、分数 $\dfrac{12}{10}$ にして素因数分解すれば表の値（$\log_{10} 2,\ \log_{10} 3$）に還元できる。
:::

:::check ③までやり切れチェック
- 実際に計算せず、まず $\log_{10}$ をとったか
- $\log_{10}$ の値を $\log_{10} 2,\ \log_{10} 3$ など与えられた値で表したか
- 桁数・小数第何位は、$10^{n-1} \le N < 10^n$ などの不等式に戻してから答えたか
- 最高位は小数部分を $\log_{10} 2,\ \log_{10} 3,\ \cdots$ と比べたか
- 「何年後」は最小の整数を答えたか
:::
