## 練習問題

:::exercise 基本
線分 AB と線分 CD が点 O で交わっていて、$AO = BO$、$CO = DO$ である。このとき、$AC = BD$ を証明せよ。
（図：線分 AB と CD が、それぞれの真ん中の点 O で交わっている。A と C、B と D を結ぶ）
:::

:::answer
【①全体を見る】仮定：$AO = BO$、$CO = DO$。結論：$AC = BD$。
【②知識の利用】$AC$ と $BD$ を辺にもつ三角形の合同を示す。
【③部分を見る】$AC$ を含む △AOC と、$BD$ を含む △BOD を取り出す。
△AOC と △BOD において
- $AO = BO$（仮定）……①
- $CO = DO$（仮定）……②
- $\angle AOC = \angle BOD$（対頂角）……③

①、②、③より、2組の辺とその間の角がそれぞれ等しいから、[[$\triangle AOC \equiv \triangle BOD$]]。
合同な図形では対応する辺は等しいから、$AC = BD$。
:::

:::exercise 標準
平行四辺形 ABCD の対角線 BD 上に、$BE = DF$ となるように点 E、F をとる。このとき、$AE = CF$ を証明せよ。
:::

:::answer
【①全体を見る】仮定：ABCD は平行四辺形、$BE = DF$。結論：$AE = CF$。
【②知識の利用】$AE$ と $CF$ を辺にもつ三角形の合同を示す。平行四辺形の性質も根拠に使える。
【③部分を見る】△ABE と △CDF を取り出す。
△ABE と △CDF において
- $AB = CD$（平行四辺形の対辺）……①
- $BE = DF$（仮定）……②
- $AB \parallel DC$ より錯角は等しいから、$\angle ABE = \angle CDF$ ……③

①、②、③より、2組の辺とその間の角がそれぞれ等しいから、[[$\triangle ABE \equiv \triangle CDF$]]。
合同な図形では対応する辺は等しいから、$AE = CF$。

③の角が、①と②の辺の「間の角」になっていることを必ず確認する（$AB$ と $BE$ の間は $\angle ABE$）。
:::

:::exercise 発展
$AB = AC$ の二等辺三角形 ABC で、頂点 B から辺 AC に垂線 BD を、頂点 C から辺 AB に垂線 CE をひく。このとき、$BD = CE$ を証明せよ。
（図：頂点 A が上の二等辺三角形。BD と CE が三角形の中で交差している）
:::

:::answer
【①全体を見る】仮定：$AB = AC$、$\angle ADB = \angle AEC = 90^\circ$。結論：$BD = CE$。
【②知識の利用】$BD$ と $CE$ を辺にもつ三角形の合同を示す。
【③部分を見る】重なった図から △ABD と △ACE を取り出す。
△ABD と △ACE において
- $AB = AC$（仮定）……①
- $\angle BAD = \angle CAE$（共通な角）……②
- 三角形の内角の和より $\angle ABD = 180^\circ - 90^\circ - \angle A$、$\angle ACE = 180^\circ - 90^\circ - \angle A$ だから $\angle ABD = \angle ACE$ ……③

①、②、③より、1組の辺とその両端の角がそれぞれ等しいから、[[$\triangle ABD \equiv \triangle ACE$]]。
合同な図形では対応する辺は等しいから、$BD = CE$。

（直角三角形の合同条件「斜辺と1つの鋭角がそれぞれ等しい」を使えば、①と②からすぐに言える。）
:::

:::check ③までやり切れチェック
- 仮定と結論を分けて書いたか
- 結論の辺・角を含む三角形を取り出して、横に並べて描いたか
- 等しい辺・角を3つ集め、それぞれに根拠（仮定・共通・対頂角・錯角・定理）を書いたか
- 合同条件の「間の角」「両端の角」になっているか確かめたか
- $\equiv$ の両側の頂点を、対応する順に書いたか
:::
