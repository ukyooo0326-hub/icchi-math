:::point 平行四辺形になるための条件
四角形は、次のどれか1つが成り立てば平行四辺形である。
1. 2組の対辺がそれぞれ平行である（定義）
2. 2組の対辺がそれぞれ等しい
3. 2組の対角がそれぞれ等しい
4. 対角線がそれぞれの中点で交わる
5. [[1組の対辺が平行で、その長さが等しい]]
:::

## 練習問題

:::exercise 基本
四角形 ABCD について、次のうち **必ず** 平行四辺形になるものをすべて選べ。正しくないものには反例をあげよ。
(ア) AB = DC、AD = BC　(イ) AD ∥ BC、AB = DC　(ウ) ∠A = ∠C、∠B = ∠D　(エ) AD ∥ BC、AD = BC　(オ) AC ⊥ BD
:::

:::answer
【①全体を見る】「〇〇ならば平行四辺形」が正しいかを判定する。
【②知識の利用】平行四辺形になるための条件5つと見比べる。
【③部分を見る】
- (ア) 2組の対辺がそれぞれ等しい → 条件2
- (イ) 平行な組（AD と BC）と等しい組（AB と DC）が別 → 反例：等脚台形
- (ウ) 2組の対角がそれぞれ等しい → 条件3
- (エ) 同じ1組 AD、BC が平行で等しい → 条件5
- (オ) 対角線が垂直なだけ → 反例：AB = AD、CB = CD で AB ≠ CB の四角形（たこ形）

答え：[[(ア)、(ウ)、(エ)]]
:::

:::exercise 標準
「ひし形ならば、対角線は垂直に交わる」の逆を書き、それが正しいかどうかを答えよ。正しくない場合は反例をあげよ。また、平行四辺形 ABCD に「AC ⊥ BD」という条件を加えると、どんな四角形になるか答えよ。
:::

:::answer
【①全体を見る】仮定と結論を確認する。仮定：ひし形である。結論：対角線が垂直に交わる。
【②知識の利用】逆は仮定と結論を入れかえる。正しくないことは反例1つで示せる。
【③部分を見る】逆：「対角線が垂直に交わる四角形は、ひし形である」
たこ形（AB = AD、CB = CD で AB ≠ CB）は対角線が垂直に交わるが、4辺が等しくないのでひし形ではない。
答え：逆は [[正しくない（反例：たこ形）]]
平行四辺形に対角線が垂直という条件を加えると [[ひし形]] になる。

（平行四辺形なら対角線は中点で交わるので、△ABO ≡ △ADO（2組の辺とその間の角）より AB = AD。平行四辺形の対辺は等しいから4辺が等しい。）
:::

:::exercise 発展
AD ∥ BC の台形 ABCD で、対角線 AC と BD の交点を O とする。△ABO と △DCO の面積が等しいことを証明せよ。
（図：上底 AD、下底 BC の台形。対角線 AC と BD が O で交わる）
:::

:::answer
【①全体を見る】仮定：AD ∥ BC。結論：△ABO ＝ △DCO（面積）。
【②知識の利用】平行線があれば、底辺が共通な三角形の面積は等しい（等積変形）。
【③部分を見る】△ABO と △DCO は直接比べにくい。どちらも、底辺 BC の三角形から △OBC を除いた部分になっている。
AD ∥ BC で、△ABC と △DBC は底辺 BC が共通、高さが等しいから
$$\triangle ABC = \triangle DBC$$
【④工夫する】両方から共通な △OBC をひく。
$$\triangle ABC - \triangle OBC = \triangle DBC - \triangle OBC$$
よって [[$\triangle ABO = \triangle DCO$]]
:::

:::check ③までやり切れチェック
- 仮定と結論を分けて書いたか
- 平行四辺形になるための条件5つから、問題文に出てくる辺・角・対角線に合うものを選んだか
- 条件5を使うとき、平行と等しいが同じ1組の対辺になっているか確認したか
- 逆の正しさは、反例（等脚台形・たこ形など）がないか探して確かめたか
- 平行線があるとき、底辺が共通で面積が等しい三角形を探したか
:::
