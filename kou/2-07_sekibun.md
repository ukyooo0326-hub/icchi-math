## 練習問題

:::exercise 基本
定積分 $\displaystyle\int_{-1}^{2} (3x^2 - 2x + 1)\,dx$ を計算せよ。
:::

:::answer
【①全体を見る】多項式の定積分。原始関数を作って、上端と下端の値の差をとる。
【②知識の利用】$\displaystyle\int (3x^2 - 2x + 1)\,dx = x^3 - x^2 + x + C$。
【③部分を見る】$F(x) = x^3 - x^2 + x$ として、$F(2)$ と $F(-1)$ を別々に計算する。
$$F(2) = 8 - 4 + 2 = 6, \qquad F(-1) = -1 - 1 - 1 = -3$$
$$F(2) - F(-1) = 6 - (-3) = 9$$
答え：[[$9$]]

よくあるミス：$F(-1)$ の符号の計算。$(-1)^2 = 1$ に $-$ がついて $-1$ になる。かっこをつけて1項ずつ代入する。
:::

:::exercise 標準
放物線 $y = x^2 - x - 2$ と $x$ 軸で囲まれた部分の面積を求めよ。
:::

:::answer
【①全体を見る】放物線と $x$ 軸（$y = 0$）で囲まれた面積。
【②知識の利用】交点から交点まで ∫(上 − 下) で出す。
【③部分を見る】交点：$x^2 - x - 2 = 0$ より $(x + 1)(x - 2) = 0$、$x = -1,\ 2$。
上下確認：$x = 0$ で $y = -2 < 0$。放物線は $x$ 軸より **下**。上は $y = 0$。
$$S = \int_{-1}^{2} \{0 - (x^2 - x - 2)\}\,dx = \int_{-1}^{2} \{-(x + 1)(x - 2)\}\,dx$$
【④工夫する】1/6 公式より
$$S = \frac{\{2 - (-1)\}^3}{6} = \frac{27}{6} = \frac{9}{2}$$
答え：[[$\dfrac{9}{2}$]]

$\displaystyle\int_{-1}^{2} (x^2 - x - 2)\,dx$ をそのまま計算すると $-\dfrac{9}{2}$ になる。$x$ 軸より下の部分は「$0 -$ 式」で積分する。
:::

:::exercise 発展
2つの放物線 $y = x^2$ と $y = -x^2 + 2x + 4$ で囲まれた部分の面積を求めよ。
:::

:::answer
【①全体を見る】放物線どうしで囲まれた面積。
【②知識の利用】やることは同じで、交点から交点まで ∫(上 − 下)。
【③部分を見る】交点：$x^2 = -x^2 + 2x + 4$ より $2x^2 - 2x - 4 = 0$、$x^2 - x - 2 = 0$、$(x + 1)(x - 2) = 0$。$x = -1,\ 2$。
上下確認：$x = 0$ で $y = x^2$ は $0$、$y = -x^2 + 2x + 4$ は $4$。後者が上。
$$S = \int_{-1}^{2} \{(-x^2 + 2x + 4) - x^2\}\,dx = \int_{-1}^{2} (-2x^2 + 2x + 4)\,dx = \int_{-1}^{2} \{-2(x + 1)(x - 2)\}\,dx$$
【④工夫する】係数 $-2$ を積分の外に出して1/6 公式。
$$S = -2 \cdot \left(-\frac{\{2 - (-1)\}^3}{6}\right) = 2 \cdot \frac{27}{6} = 9$$
答え：[[$9$]]

よくあるミス：交点を求めるときに両辺を $2$ で割った $x^2 - x - 2$ をそのまま被積分関数に使い、$\dfrac{9}{2}$ と答える。割ってよいのは方程式（$= 0$ の式）だけで、積分する「上 − 下」は割ってはいけない。
:::

:::check ③までやり切れチェック
- 2つのグラフを連立して交点を求め、積分区間を決めたか
- 区間内の値を1つ代入して、どちらが上か確認したか
- 「上 − 下」の順で被積分関数を作ったか
- 原始関数に上端・下端を代入するとき、かっこをつけて符号を確認したか
- 1/6 公式を使うとき、$x^2$ の係数をかけ忘れていないか
:::
