## 練習問題

:::exercise 基本
関数 $y = 3x^2$ について、$x$ の値が 2 から 5 まで増加するときの変化の割合を求めよ。
:::

:::answer
【①全体を見る】$y = ax^2$ の変化の割合。一定ではないので、区間 2 から 5 を確認する。
【②知識の利用】$a(p + q)$ を使う。
【③部分を見る】$a = 3$、$p = 2$、$q = 5$。
$$3 \times (2 + 5) = 21$$
検算：$x = 2$ で $y = 12$、$x = 5$ で $y = 75$。$\dfrac{75 - 12}{5 - 2} = \dfrac{63}{3} = 21$。

答え：[[21]]
:::

:::exercise 標準
関数 $y = ax^2$ について、$x$ の値が 1 から 3 まで増加するときの変化の割合が 12 であった。$a$ の値を求めよ。
:::

:::answer
【①全体を見る】求めるのは $a$。変化の割合がわかっているので、$a$ についての方程式を作る。
【②知識の利用】変化の割合は $a(p + q)$。
【③部分を見る】$p = 1$、$q = 3$ を入れる。
$$a(1 + 3) = 12$$
$$4a = 12$$
答え：[[$a = 3$]]

よくあるミス：一次関数と同じだと思って「変化の割合＝$a$」から $a = 12$ とする。
:::

:::exercise 発展
関数 $y = x^2$ のグラフ上に、$x$ 座標がそれぞれ $-1$、$3$ である2点 A、B がある。原点を O とする。
(1) 直線 AB の式を求めよ。
(2) △OAB の面積を求めよ。
（図：放物線 $y = x^2$ と、その上の2点 A、B を結ぶ直線。直線 AB は $y$ 軸と点 C で交わる）
:::

:::answer
【①全体を見る】(1) のゴールは直線の式 $y = mx + n$。傾き $m$ と切片 $n$ がわかればよい。
A$(-1,\ 1)$、B$(3,\ 9)$ である。
【②知識の利用】直線 AB の傾きは、$x$ が $-1$ から $3$ まで増加するときの変化の割合に等しい。
$$1 \times (-1 + 3) = 2$$
$y = 2x + n$ に B$(3,\ 9)$ を代入して $9 = 6 + n$、$n = 3$。

(1) 答え：[[$y = 2x + 3$]]

【③部分を見る】(2) △OAB をそのまま見ると、底辺も高さもはっきりしない。$y$ 軸で2つの三角形に分ける。
直線 AB と $y$ 軸の交点は C$(0,\ 3)$。OC $= 3$ を共通の底辺とみると、高さはそれぞれ A、B の $x$ 座標の絶対値 1 と 3。
$$\triangle OAC + \triangle OBC = \frac{1}{2} \times 3 \times 1 + \frac{1}{2} \times 3 \times 3 = \frac{3}{2} + \frac{9}{2} = 6$$
(2) 答え：[[6]]
:::

- 変化の割合の定義「$y$ の増加量 ÷ $x$ の増加量」を言えたか
- $y = ax^2$ の変化の割合は一定ではない、と区間を確認したか
- $a$、$p$、$q$ を符号ごと取り出したか
- $y$ の値を出すとき、2乗を先に計算してから $a$ 倍したか
