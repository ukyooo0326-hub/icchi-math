## 練習問題

:::exercise 基本
$0^\circ \le \theta \le 180^\circ$ とする。$\sin\theta = \dfrac{1}{3}$ のとき、$\cos\theta$ と $\tan\theta$ の値を求めよ。
:::

:::answer
【①全体を見る】$\sin\theta$ がわかっていて、$\cos\theta$ と $\tan\theta$ を求める。$\theta$ の範囲は $0^\circ$〜$180^\circ$。
【②知識の利用】相互関係 $\sin^2\theta + \cos^2\theta = 1$ と $\tan\theta = \dfrac{\sin\theta}{\cos\theta}$。
$$\cos^2\theta = 1 - \frac{1}{9} = \frac{8}{9}$$
【③部分を見る】$\sin\theta > 0$ は鋭角でも鈍角でも成り立つので、$\cos\theta$ の符号で場合分けする。
- $\theta$ が鋭角のとき：$\cos\theta = \dfrac{2\sqrt{2}}{3}$、$\tan\theta = \dfrac{1}{3} \div \dfrac{2\sqrt{2}}{3} = \dfrac{1}{2\sqrt{2}} = \dfrac{\sqrt{2}}{4}$
- $\theta$ が鈍角のとき：$\cos\theta = -\dfrac{2\sqrt{2}}{3}$、$\tan\theta = -\dfrac{\sqrt{2}}{4}$

答え：[[$(\cos\theta,\ \tan\theta) = \left(\dfrac{2\sqrt{2}}{3},\ \dfrac{\sqrt{2}}{4}\right),\ \left(-\dfrac{2\sqrt{2}}{3},\ -\dfrac{\sqrt{2}}{4}\right)$]]

よくあるミス：鋭角の答えだけ書く。$0^\circ$〜$180^\circ$ では $\sin$ の値1つに角が2つある。
:::

:::exercise 標準
$\triangle ABC$ において $a = 5$, $b = 6$, $c = 7$ のとき、$\cos A$、$\sin A$、面積 $S$ を求めよ。
:::

:::answer
【①全体を見る】3辺がわかっていて、角の情報はない。
【②知識の利用】ペアがないので余弦定理。角 $A$ の向かいの辺 $a$ を引き、挟む2辺 $b$, $c$ で割る。
$$\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{36 + 49 - 25}{2 \cdot 6 \cdot 7} = \frac{60}{84} = \frac{5}{7}$$
【③部分を見る】$\cos A$ は有名角の値ではない。面積に必要な $\sin A$ は相互関係から出す。$\sin A > 0$ なので
$$\sin A = \sqrt{1 - \left(\frac{5}{7}\right)^2} = \sqrt{\frac{24}{49}} = \frac{2\sqrt{6}}{7}$$
2辺 $b$, $c$ とその間の角 $A$ で面積公式。
$$S = \frac{1}{2} \cdot 6 \cdot 7 \cdot \frac{2\sqrt{6}}{7} = 6\sqrt{6}$$
答え：[[$\cos A = \dfrac{5}{7}$、$\sin A = \dfrac{2\sqrt{6}}{7}$、$S = 6\sqrt{6}$]]

角が有名角でなくても、$\cos \to \sin \to$ 面積 の順で必ず進める。
:::

:::exercise 発展
$\triangle ABC$ において $a = \sqrt{2}$, $b = 2$, $A = 30^\circ$ のとき、$B$ と $c$ を求めよ。
:::

:::answer
【①全体を見る】わかっているのは $a$, $b$, $A$。求めるのは $B$ と $c$。
【②知識の利用】$(a, A)$ のペアがそろっているので正弦定理で $B$ を出せる。
$$\sin B = \frac{b\sin A}{a} = \frac{2 \cdot \frac{1}{2}}{\sqrt{2}} = \frac{1}{\sqrt{2}}$$
【③部分を見る】$\sin B = \dfrac{1}{\sqrt{2}}$ をみたす角は $B = 45^\circ$ と $B = 135^\circ$ の2つ。三角形の角として成り立つか確認する。
- $B = 45^\circ$：$A + B = 75^\circ < 180^\circ$ なので成立。$C = 105^\circ$
- $B = 135^\circ$：$A + B = 165^\circ < 180^\circ$ なので成立。$C = 15^\circ$

【②知識の利用（もう一度）】$c$ は、角 $A$ の余弦定理で $c$ についての2次方程式にする。
$$(\sqrt{2})^2 = 2^2 + c^2 - 2 \cdot 2 \cdot c \cos 30^\circ$$
$$c^2 - 2\sqrt{3}\,c + 2 = 0$$
解の公式より $c = \sqrt{3} \pm 1$（どちらも正）。
【③部分を見る（もう一度）】どちらの $c$ がどちらの $B$ に対応するか、角 $B$ の余弦定理で確かめる。
- $c = \sqrt{3} + 1$ のとき：$\cos B = \dfrac{a^2 + c^2 - b^2}{2ac} = \dfrac{2 + 2\sqrt{3}}{2\sqrt{2}(\sqrt{3} + 1)} = \dfrac{1}{\sqrt{2}}$ なので $B = 45^\circ$
- $c = \sqrt{3} - 1$ のとき：$\cos B = \dfrac{2 - 2\sqrt{3}}{2\sqrt{2}(\sqrt{3} - 1)} = -\dfrac{1}{\sqrt{2}}$ なので $B = 135^\circ$

答え：[[$B = 45^\circ$, $c = \sqrt{3} + 1$ または $B = 135^\circ$, $c = \sqrt{3} - 1$]]

三角形が2通りできるのは、「2辺とその間にない角」が与えられたときの典型。$\sin$ から角を出したら2つ調べる。
:::
