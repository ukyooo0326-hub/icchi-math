## 練習問題

:::exercise 基本
>>1 と同じ図で、$\ell \parallel m$、$\angle CAP = 28^\circ$、$\angle DBP = 47^\circ$ のとき、$\angle APB$ を求めよ。
:::

:::answer
【①全体を見る】ゴールは $\angle APB$。「平行」があるので錯角を使う。
【②知識の利用】平行線の錯角は等しい。
【③部分を見る】P のまわりに平行線がない。
【④工夫する】P を通り $\ell$ に平行な直線を引き、P より左に点 E をとる。
- $\angle APE = \angle CAP = 28^\circ$（$\ell$ と PE の錯角）
- $\angle EPB = \angle DBP = 47^\circ$（PE と $m$ の錯角）
$$\angle APB = 28^\circ + 47^\circ = 75^\circ$$
答え：[[$75^\circ$]]
:::

:::exercise 標準
五角形 ABCDE で、$\angle A = 100^\circ$、$\angle B = 110^\circ$、$\angle C = 120^\circ$、$\angle D = 95^\circ$ のとき、$\angle E$ を求めよ。
:::

:::answer
【①全体を見る】ゴールは $\angle E$。五角形の内角の和がわかれば、引き算で出る。
【②知識の利用】知っているのは「三角形の内角の和は $180^\circ$」だけ。
【③部分を見る】頂点 A から対角線 AC、AD を引くと、五角形は三角形3つに分かれる。
$$\text{内角の和} = 180^\circ \times 3 = 540^\circ$$
$$\angle E = 540^\circ - (100^\circ + 110^\circ + 120^\circ + 95^\circ) = 540^\circ - 425^\circ = 115^\circ$$
答え：[[$115^\circ$]]

一般に $n$ 角形は三角形 $(n-2)$ 個に分けられるので、内角の和は [[$180^\circ \times (n-2)$]]。多角形も三角形に還元できる。
:::

:::exercise 発展
（図：5つの点 A、B、C、D、E が円をえがくようにこの順に並び、線分 AC、CE、EB、BD、DA で結んだ星形）
星形の5つの先の角 $\angle CAD$、$\angle DBE$、$\angle ACE$、$\angle ADB$、$\angle BEC$ の和を求めよ。
:::

:::answer
【①全体を見る】ゴールは5つの角の和。1つずつは求められないので、和をまとめて1か所に集めたい。
【②知識の利用】角を集める道具は「三角形の外角＝隣り合わない2つの内角の和」。
【③部分を見る】AC と BE の交点を F、AD と BE の交点を G とし、△AGF に視野を絞る。
- $\angle AFG$ は △FCE の外角なので $\angle ACE + \angle BEC$
- $\angle AGF$ は △GBD の外角なので $\angle DBE + \angle ADB$

よって5つの角の和は、△AGF の3つの内角 $\angle CAD + \angle AFG + \angle AGF$ と等しい。
答え：[[$180^\circ$]]

【④工夫する】「バラバラの角を外角で1つの三角形に集める」のは、知っている「内角の和 $180^\circ$」に持ち込むため。
:::

:::check ③までやり切れチェック
- ゴールの角と、「平行」の条件があるかを確認したか
- 使う性質（錯角・同位角・内角の和・外角）の条件を満たしているか確かめたか
- ゴールの角の頂点のまわりに、「平行な2直線と交わる1本」のセットがあるか見たか
- なければ「平行線を引く」「三角形を作る」という候補を出したか
:::
